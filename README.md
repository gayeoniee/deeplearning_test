## 문제를 둘로 쪼갰습니다

*"병원에 가봐야 하나?"* 와 *"무슨 병변인가?"* 는 임상적 무게가 다른 질문입니다.
7클래스 손실함수는 **정상을 병변이라 부른 오류**와 **병변끼리 헷갈린 오류**를
똑같이 취급하고, *"놓치지 않는 게 우선"* 인 임계값을 앞쪽에만 걸 수도 없습니다.

| | 1단계 | 2단계 |
|---|---|---|
| 질문 | 정상 / 이상 | 병변 6종 (A1~A6) |
| 확정 설정 | `effnetv2_s` + `f320` + `photometric` | `convnextv2_base` + `m2.5` |
| 우선하는 것 | **놓치지 않기** (recall) | 헷갈림 줄이기 (macro-F1) |

두 단계는 **하나의 분할을 공유하는 두 뷰**(`src/stages.py`)이고 학습 때는 서로
안 봅니다 — 추론에서만 이어집니다. 그래서 한쪽만 따로 실험할 수 있습니다.

**A1~A6 은 병명이 아니라 병변의 형태입니다.**

| 코드 | 병변 형태 | 긴급도 |

| A2 | 비듬·각질·상피성잔고리 | 관찰 |
| A3 | 태선화·과다색소침착 | 진료 권장 |

# 전 — 그런데 그 숫자는 실사용 숫자가 아니었습니다 (STEP 36~45)

## 우리는 **라벨러가 그린 네모**로 잘라서 평가하고 있었습니다

실사용자에게는 정답 bbox 가 없습니다. 앱은 **촬영 가이드 프레임**을 bbox
대신 받는데, 사람이 그 네모를 어떻게 그리는지를 **두 달 동안 안 쟀습니다.**
재보니:

| | 라벨 네모 | **사용자 네모** | |
|---|---:|---:|---|
| 2단계 macro-F1 | — | — | 상대 **−22~24%** |
| 정확도 | 67.6% | 61.7% | −8.6% |
| 확신도 변별력 AUROC | 0.7192 | 0.6484 | −9.8% |
| **커버리지** | **50.3%** | **22.4%** | **−55.5%** |

> ★★ **커버리지는 작은 하락을 6배로 증폭합니다.** 정확도와 순위 품질이 각각
> 9%씩 빠지는데 커버리지는 55% 무너집니다 — *"누적 오답률 20%를 안 넘는
> 지점까지"* 라는 **문턱 지표**라서요. 정직하지만(하한선 0%) 취약합니다.

## 그리고 더 나쁜 것 — 그 네모는 **이미 쓰이지 않고 있었습니다**

`m2.5` 창 = 네모 긴 변 × 2.5 입니다. 사진이 1080px 이면 네모가 화면의
**47%만 넘어도 창이 사진을 통째로 덮습니다.** 실측 사용자 네모는 47.2~70.6% —
**40장 전부(100%)가 창을 포화**시킵니다.

    배포 모델 2단계 macro-F1
      사용자 네모  0.3720      네모 없음(사진 전체)  0.3720   ← 소수점까지 같음

**이 계산에는 모델도 GPU 도 필요 없었습니다.** `crop_window()` 를 몇 번 부르면
나옵니다. 그런데 사람 40장을 두 번 그리게 하고 파인튜닝을 세 번 돌린 **뒤에야**
했습니다.

> ⚠️ 일반화: **비싼 측정 전에 "이 입력이 실제로 쓰이기는 하나" 를 산수로
> 확인하세요.** 파이프라인에 클리핑·클램프가 있으면 상류 변화가 하류에
> **아예 안 닿을 수 있습니다.**

## 그래서 열한 갈래를 열어봤고, 그 조건에서는 전부 닫혔습니다

| 갈래 | 결과 | |

**A2 병목이 그대로 남아 있습니다** (STEP 11 에서 이미 본 것).
그리고 화질 연관성도 방향이 같습니다 — 정상은 **선명한** 쪽에서(AUROC .769),
A2 는 **흐린** 쪽에서(.302, 즉 반대 방향) 틀립니다.
⚠️ 관찰이고 개입 실험이 아닙니다. 교란 추론은 아직 안 돌렸습니다.

# 결 — 그래서 화면에 무엇을 말하나

6종 이름은 **안 말합니다.** holdout 에서 46.3% 틀리고, 거절로 살리려 해도
쓸 수 있는 커버리지가 릴리스 단독 **0.7%** 입니다.

대신 **형태 계열 네 묶음**을 말합니다 (2026-09-08 결정).

| 묶음 | 무엇 | holdout 포착률<br>(릴리스 단독) | (3팔 앙상블) |
|---|---|---:|---:|
| 융기·발진 | A1 구진·플라크 + A4 농포·여드름 | 31.9% | **51.3%** |
| 표면 변화 | A2 비듬·각질 + A3 태선화·색소침착 | 71.9% | — |
| 미란·궤양 | A5 | 38.0% | — |
| **결절·종괴** | **A6 — 따로 둡니다** | 46.7% | **54.5%** |

⚠️ **팔을 섞어 인용하지 마세요.** 앙상블은 **묶은 자리**(A1↔A4)에서 1.6배로
좋아지고 A5 는 묶음 **사이**라 거의 그대로입니다. 앙상블 열의 `—` 는 값이
없다는 뜻이 아니라 **이 표에 안 실었다**는 뜻입니다.

**A6 을 왜 따로 두나** — 3군 대비 커버리지를 0.7%p 만 잃으면서 **종양 감별이
필요한 유일한 클래스의 이름을 지킵니다.** A5 와 묶어 *"손상·덩어리"* 로
부르면 그 뜻이 사라집니다.

**묶음의 근거는 데이터가 아니라 문헌입니다** — primary/secondary 축(MSD·
Clinicians Brief), **1cm 경계**(구진 ≤1cm / 결절 >1cm, Cornell — **A6 를 따로
둔 근거**), **표피 소실 여부**(A5 를 가르는 선), 그리고 A2+A3 는 ICADA
가이드라인(Hensel et al. 2015, BMC Vet Res) 한 문장에 같이 있습니다.
혼동행렬을 보고 묶으면 무슨 묶음이든 좋아지므로 **데이터를 보기 전에** 정했습니다.

> 🔴 **2026-09-10 정정 — 근거 서술 셋을 고쳤습니다** (판정은 그대로).
> ① *"융기·발진 = ≤1cm"* → **플라크는 보통 >1cm**. 1cm 는 *구진 vs 결절* 의
> 경계이지 묶음 전체 크기가 아닙니다 ② *"표면 변화 = 장벽 온전"* → **표피잔고리는
> 농포가 터진 뒤** 남는 것이라 온전하지 않습니다 ③ *"미란·궤양 = 2차 감염 위험"*
> → 그건 뒤따르는 위험이고 **정의는 표피의 소실**입니다.
> ⚠️ 화면 문구에는 이 정의가 안 나갑니다 — 고친 것은 **우리가 근거로 적어둔
> 서술**입니다. 자세한 것은 [`STEP32`](docs/results/STEP32_수의학축_검증과_앙상블_값어치.md).

### 안전장치 셋

1. **거절** — 확신도(`p(이상) × p(계열)`)가 문턱 미만이면 **아무 이름도 안 말하고**
   진료를 권합니다. 커버리지 66.5% 는 *"열에 일곱쯤 말한다"* 는 뜻입니다.
2. **하향 방지 규칙** — 급한 쪽(A5+A6) 확률 합이 0.25 이상이면 덜 급한 묶음을
   답 후보에서 뺍니다. 추론 0회로 A5 하향 43.8% → **36.8%**.
3. **긴급도를 계열 이름과 같이 안 띄웁니다** — 같이 띄우면 말한 것의 절반이
   한 단계 부풀려집니다 (과잉 49.3%).

### 최종 관문

| | 값 | 허용 | |
|---|---:|---:|---|
| 계열 4군 커버리지 | **66.5%** | ≥ 50% | ✅ |
| 긴급도 **하향** (급한 걸 안 급하다고) | **2.9%** | ≤ 5% | ✅ |
| A6 오명명 | **12.5%** | ≤ 30% | ✅ |

하향 문턱 5% 의 **닻**: 1단계가 병변의 5.70% 를 놓치고 그건 *"괜찮아 보여요"*
로 나가는 **완전한 하향**입니다. 2단계의 부분 하향(조기진료 → 진료권장,
병원에는 감)은 그보다 **작고 약해야** 합니다 — `0.05 < 0.057`.

### 아직 못 하는 것 — 숨기지 않습니다

- **A5(미란·궤양) 포착 38.0%**(릴리스 단독) — A1·A4 와 안 갈립니다. 짝별 AUROC 최악 셋 중
  둘이 A5. 소거법으로 남은 설명은 *"입체감이 사진 한 장에 안 찍힌다"* 이고,
  고치는 길은 모델이 아니라 **촬영**(비스듬한 조명·두 각도)입니다
- **A4(농포) recall 0.264** — 로짓 보정으로 개입 실험했더니 A2·A3 가 정확히
  그만큼 내려가는 **순수 맞바꿈**이었습니다. 표현의 문제입니다
- **실사용자 사진에서의 성능** — 위 숫자는 전부 라벨 네모 기준입니다.
  열한 갈래가 닫힌 지금, 이건 **여는 길이 아직 없습니다**
- **새 전체 데이터(370,671장) 재학습** — 원본 확보와 전체 학습은 다릅니다.
  최근 것은 각 20,000장 **파일럿**입니다
- **A6 경보는 재현율로 정하세요** — 정밀도는 모델이 아니라 **모델 × 유병률**의
  성질이라 문턱을 고정해도 안 고정됩니다 (val 4.61% vs holdout 2.91%)

# 이 프로젝트에서 배운 것

숫자보다 이쪽이 오래 갑니다. 전부 **실제로 당한 것**이고, 각각 검사로 못 박았습니다.

| | |
|---|---|
| **하한선 없는 정확도는 숫자가 아닙니다** | 계열 3군 정확도 0.8365 를 개선 근거로 앞세웠는데, 최빈 묶음이 이미 67.1% 였습니다. 하한선 대비로는 **6종 +35.1%p vs 3군 +16.5%p** 로 **방향이 뒤집힙니다.** 문제를 쉽게 만들면 모델의 몫은 줄어듭니다 |
| **사전등록에는 문턱과 하한선을 같이** | 검출기 문턱 50% 는 미리 박았는데 하한선을 안 적었습니다. 나중에 재보니 *아무것도 안 배운 네모*가 배율 72.3% — 순이득은 +2.7%p 뿐이고 실제로 배운 건 **위치**였습니다. 그리고 하한선(6.1%)이 앞선 두 STEP 의 측정값(5.0%·6.7%)과 같은 구간이라 **그 둘은 아무것도 안 한 것과 구분이 안 됐습니다** |
| **관문을 한쪽만 세면 반대쪽으로 도망칩니다** | 하향 1.7% 로 안심하는 동안 **과잉이 49.3%** 였습니다. 전부 *"조기 진료"* 라고 말하면 하향은 0% 입니다. → 관문으로 안 쓰더라도 **반대쪽을 같이 찍으세요** |
| **평균이 통과하는 관문은 한 클래스를 묻습니다** | 전체 하향 3.7% 가 관문(5%)을 통과하는 동안 **말한 A5 의 43.8%** 가 하향이었습니다. 분모가 큰 클래스가 평균을 삽니다 |
| **대조군이 없으면 분포 적응을 효과로 읽습니다** | 잡음 증강이 +0.111 이라 좋아 보였는데, 같은 예산의 **대조군(잡음 0%)만으로 +0.109** 였습니다 |
| **두 팔이 두 가지로 다르면 아무것도 못 잽니다** | STEP 44 가 그랬고, 대조군을 바꾼 STEP 45 에서야 답이 나왔습니다 |
| **각주는 재는 것의 대체가 아닙니다** | *"이 곡선은 헛알림을 뺀 것이라 실제는 더 나쁩니다"* 라고 **정확히 적어놓고** 아무도 안 쟀습니다. 두 달 뒤 각주는 안 따라오고 숫자만 남아 잘못된 재검토를 했습니다. → 각주를 달 거면 **재는 코드를 같이** 만드세요 |
