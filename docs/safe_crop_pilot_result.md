보존 crop은 기본 임계값 0.5에서 거의 모든 사진을 이상으로 예측한다. 정상 사진의 이상 확률 중앙값도 0.9455다. AUROC는 일반 crop과 비슷하므로 분류 순위 정보가 완전히 소실된 상황은 아니다. 원인을 증강이나 BatchNorm 중 하나로 확정할 근거는 아직 없다.

검증셋의 그룹을 유지한 5-fold 교차 진단도 수행했다. 각 fold 밖에서 macro F1을 최대화하는 임계값을 고르고 해당 fold에 적용했다(301개 분위수 후보, seed 42). 일반 crop F1 0.6498, recall 0.5931, specificity 0.7102. 보존 crop F1 0.6550, recall 0.6422, specificity 0.6684. 보존 crop 임계값은 약 0.958–0.969로 이동했다. 차이가 작고 같은 검증셋을 탐색 중이므로 독립 평가 성능이나 유의한 개선을 뜻하지 않는다. holdout은 사용하지 않았다.

현재 결과만으로 유료 GPU의 전체 재학습을 권하지 않는다. 추가 epoch를 그대로 이어갈 이유도 부족하다. 먼저 임계값 이동과 학습/검증 입력 차이를 점검하는 것이 적절하다.
