## 0. 먼저 용어 다섯 개

| 말 | 뜻 |
|---|---|
| **1단계 / 2단계** | 1단계는 "정상인가, 이상한가" 만 봅니다. 이상하면 2단계가 "어떤 모양의 병변인가"(6종)를 봅니다 |
| **recall (놓치지 않는 비율)** | 진짜 병변 100장 중 "이상" 이라고 맞춘 장수. 놓친 병변은 "괜찮아 보여요" 로 나가므로 **제일 비싼 실수**입니다 |
| **헛알림** | 정상 사진 100장 중 "이상" 이라고 한 장수. 보호자가 괜히 병원에 가는 비율 |
| **커버리지** | 2단계가 "이건 OO 계열 같아요" 라고 **말해도 되는** 사진 비율. 틀릴 확률이 20% 를 넘으면 말 안 하고 "판단 어려움" 으로 물러섭니다. 말을 많이 하면서도 틀리지 않아야 올라갑니다 |
| **holdout / val / 프록시** | **holdout** = 마지막에 한 번만 보는 시험지(제일 믿을 만함). **val** = 개발 중 보는 시험지. **프록시** = 실제 보호자 사진이 없어서 *"보호자처럼 찍고 대충 네모 그린 것처럼"* 흉내 낸 검사 — 절대값은 믿지 말고 **두 후보의 차이**만 봅니다 |

## 2. 흐름 — 여덟 구간

### ① 뼈대와 기준선 (STEP 1~5, 8월 중순)
- 데이터: AI Hub 반려견 피부 질환(일반 카메라만). 사진 한 장에 라벨 네모(bbox) 하나. 개체 단위로 train/val/holdout 을 갈라 **같은 개가 양쪽에 안 가게** 했습니다(데이터 누수 방지).
- 문제를 **1단계(정상/이상) → 2단계(6종)** 로 나눴습니다. 이름은 병명이 아니라 **병변 모양**입니다.
- 기준선을 잡고 규칙을 정했습니다: 숫자는 실측만, 판정 기준은 돌리기 전에 못 박기, 하한선(사진 없이 맞히기)과 비교하기.
- 결과: 2단계 macro-F1 0.55 언저리(val). 로드맵의 0.70~0.80 예상은 **틀렸다**고 적었습니다.

### ② 1단계가 시험지 밖에서 무너짐 → 고침 (STEP 6~10)
- 1단계가 holdout 에서 AUROC 0.81 → 0.74 로 떨어졌습니다. 원인은 **화질 지름길**: 정상 사진이 흐린 편이라 모델이 "흐리면 정상" 을 배웠습니다(흐리게 하면 0.74 → 0.33).
- 고친 것 둘: 흐림·노이즈 증강(`photometric`) + 네모 크기를 안 쓰는 **고정 320px 창(f320)**. holdout AUROC **0.9304** 로 해결.
- 같은 recall 에서 헛알림 59% → 33%.

### ③ 데이터 8배, 확정 재학습 (STEP 11~16, 8월 말)
- 데이터 45,885 → **365,428장**. 2단계 백본을 convnextv2_base 로 확정(holdout macro-F1 **0.5990**).
- 좋아진 것: A6(혹) recall 0.33 → 0.62, 헛알림 33 → 21%, 놓침 7.0 → 4.5%.
- 안 좋아진 것: A4(농포) recall 0.26 으로 최악 — A1(구진)과 사진으로는 안 갈립니다(속의 고름이 안 찍힘).
- **화면에서 6종 이름을 뺐습니다** — holdout 에서 이름이 46.3% 틀립니다.

### ④ 왜 놓치고 왜 헷갈리나 (STEP 17~24, 9월 초)
- 1단계는 **큰 병변**을 놓칩니다(창을 넘치는 병변). 창을 키워도(f448) 안 나아져서 "창 탓" 은 아니었습니다.
- 헛알림은 **털처럼 가는 선이 많은 선명한 사진**에서 납니다. 견종이 아니라 "그 사진에 찍힌 털" 입니다 → 촬영 가이드 "털을 헤쳐서 피부가 보이게".
- 2단계 고정 창(f320)이 VL01 한 조각에서만 좋아 보였다가 전체에서 기각 — **한 조각 결과를 믿지 말 것**을 두 번 배웠습니다.

### ⑤ 앙상블 — 2단계를 살린 것 (STEP 25~26)
- m2.5(비례 창) 모델과 f320(고정 창) 모델의 확률을 평균하니 **여섯 클래스 전부** 올랐습니다. 값어치는 정확도보다 **"언제 맞는지 아는 것"** — 확신 있을 때만 말하는 커버리지가 0.7% → 33.7% 로 48배.
- 배율·위치 교란 7조건에서 전부 단일 모델을 이겨서 채택. 추론 비용은 3배가 아니라 **1.36배**(실측).

### ⑥ 화면에 뭘 말할까 (STEP 27~35)
- "6종 이름" 은 너무 잘게 묻는 것이었습니다. 같은 확률로 **계열 4묶음**을 물으면 커버리지 **66.5%(holdout)**.
- 안전장치 둘: 급한 걸 안 급하다고 하는 **하향** ≤ 5%(1단계가 이미 5.7% 놓친다는 닻), 반대쪽 **과잉**도 같이 찍기.
- A5(상처)가 하향 43.8% 로 묻혀 있던 걸 찾아 **하향 방지 규칙**(급한 쪽 합 ≥ 0.25) 추가. 수의학 문헌 대조로 묶음 근거 확인, 이름을 보호자 말로 바꿈.
- 배포: 허깅페이스 리포에서 가중치를 받고 리비전 고정, 팔 수가 안 맞으면 503.

### ⑦ 보호자 네모의 현실 (STEP 36~43)
- 사람 40명이 그린 네모를 재보니 병변의 **2.8배**, 중심 이탈 0.16. 그리고 **m2.5 창은 네모가 화면의 47% 만 넘어도 사진 전체로 포화** → 2단계는 이미 사진 전체를 보고 있었습니다(가이드 네모가 2단계 결과를 안 바꿈, 소수점까지 같음).
- 반면 **1단계는 중심을 쓰므로** 네모를 없애면 recall −0.12 로 무너집니다(STEP 43). "네모 없애자" 는 여기서 한 번 닫혔습니다.
- 입력 쪽 길 아홉 개(네모 크기·점 찍기·모델 제안·기본값·f320 전환·잡음 증강·고정 배율·검출기·틀 제거)가 **전부 사전등록 관문에서 졌습니다.**

### ⑧ 마지막 두 갈래 — 창 흔들기와 검출기 (STEP 44~54, 9월 9~13일)
- **창 흔들기(멘토 제안)**: 1단계에선 두 번 졌습니다(STEP 45·48 — 정상 사진엔 보존할 병변이 없어 분포가 갈림). **2단계에선 후보**(STEP 49 파일럿: 위치 강건성 +25%p, clean −0.02). 그 확대판이 **지금 캐글에서 도는 STEP 53** 입니다.
- **검출기(멘토 피드백 2차)**: 좌표 회귀(STEP 42·50) → 진짜 object detection D-FINE(STEP 51) → 정상을 같이 가르친 1단계 후보(STEP 52). 셋 다 기각. 위치 오차가 모델·데이터를 바꿔도 0.10~0.13 에서 같은 자리 = 벽은 **라벨**(번진 병변엔 중심이 없음). STEP 52 는 같은 표본에서 헛알림 37.5% vs 현 1단계 34.0%.
- 여기서 큰 교훈 하나: **1팔로 재면 +8.3%p 통과, 배포 3팔로 재면 −0.9%p** (STEP 50). 그래서 작업 규칙 7 — 판정은 반드시 **배포 구성 + 보호자 조건**에서.

## 4. 이대로 확정해도 되나 — 제 판단

### 결론: **예, 지금 배포 구성으로 확정해도 됩니다.** 단, 아래 세 가지를 문서에 같이 적는 조건으로.

**왜 확정해도 되나**
1. 지금 구성(1단계 f320 사용자 중심 · 2단계 3팔 · 계열 4묶음 · 하향 방지)은 **모든 대안이 사전등록 관문에서 진 뒤에 남은 것**입니다. 입력 쪽 9갈래, 위치 모델 3종, 창 흔들기(1단계), 검출기 1단계 후보 — 전부 배포 구성·보호자 조건에서 현 구성을 못 이겼습니다. "더 해볼 게 있는데 안 한 것" 이 아니라 "해봤고 졌다" 입니다.
2. holdout 숫자(1단계 0.93 · 2단계 0.60 · 커버리지 66.5%)는 val 과 격차가 작고(0.023 · −1.9%p) 재현됐습니다.
3. 안전장치가 코드와 검사로 고정돼 있습니다: 6종 이름 안 나감, 하향 ≤ 5%, 팔 수 불일치 시 503, holdout 여는 노트북 목록 고정.

**같이 적어야 할 세 가지 (숨기면 안 되는 것)**
1. **보호자 조건에서는 상한의 절반쯤입니다.** 1단계 recall 87 → 73%, 커버리지 59 → 32%(프록시). 절대값은 프록시가 가혹해서 실제와 다르지만, **"라벨 네모 값은 상한" 이라는 말은 발표·문서 어디서든 같이 나가야** 합니다.
2. **실제 보호자 사진으로는 한 번도 못 쟀습니다.** 프록시는 "창을 병변의 3.5~6배로 잡고 위치를 무작위로" 흉내 낸 것입니다(`docs/cautions/10`). 앱 사진 100~200장만 모여도 프록시가 얼마나 가혹했는지 눈금을 맞출 수 있습니다 — 이게 다음 가장 값싼 일입니다.
3. **A4(농포)와 A5(상처)는 사진으로 잘 안 갈립니다.** 계열 묶음이 A4 를 덮어주지만 A5 는 묶음 사이에 홀로 남아 포착 0.51. 모델보다 **촬영(비스듬한 조명)** 쪽 숙제입니다.

**아직 열려 있는 것 하나**
- **STEP 53**(캐글 실행 중): 2단계 팔 하나를 창 흔들어 다시 배운 것으로 바꾸면 보호자 조건 커버리지가 +5%p 오르나. 통과하면 팔 하나만 교체(HF `v2`), 아니면 지금 구성 그대로 확정. 어느 쪽이든 **구조는 안 바뀝니다.**
