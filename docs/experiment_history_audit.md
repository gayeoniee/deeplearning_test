# 실험 이력 대조와 ROI 오답 분석

현재 결론: 시도를 소진한 것이 아니다. 이미 효과가 확인됐던 설정을 새 데이터에서
빠뜨리지 않고 확인하는 일이 먼저다. 신규 백본·털 가중 샘플러·증강 7종 스윕을
새 아이디어처럼 반복하지 않는다.

## 근거의 수준

- 과거 실험: HISTORY/STATUS, 아래 STEP별 실측 문서 및 해당 실행 코드 대조.
  STEP 문서가 가리키는 루트 `reports/` 폴더는 현재 없다. 과거 수치는 기록상
  완료로 분류하며 이번에 원시 예측으로 모두 재검증했다는 뜻은 아니다.
- 최근 두 파일럿: 다운로드 ZIP, protocol, history, 예측 파일과 실행 소스 SHA.
  ROI epoch 5 F1/AUROC 재계산 완료. 이번 분석은 최고 검증 F1인 epoch 3 사용.
- 데이터 준비: `data/work/safe_crop_v1/split_report.json`과 실제 패키지 manifest.
  평가·분석을 위해 holdout을 새로 열거나 학습 데이터를 수정하지 않았다.

## 이번 최고 고정 ROI 모델의 오답

조건: epoch 3, threshold .5, 같은 검증 4,000장. 과거 recall .95 기준 오답 수와
직접 비교하지 않는다. 이진 모델이므로 정상 오탐을 A2/A3로 예측했다고 말할 수 없다.

- 정상 오탐 **231/1,960 (11.79%)**.
- 병변 놓침 **348/2,040 (17.06%)**.
- 놓침: A1 75, **A2 175**, A3 69, A4 11, A5 1, A6 17.
- A2 놓침률 **25.40%**, 전체 놓침의 **50.29%**. 과거와 같은 병목이 남음.
- 두 모델 모두 오답 399장, fixed만 오답 180장, safe만 오답 338장.
  safe가 모든 사진에서 나쁜 것은 아니다. epoch 3 A2/A6 놓침은 줄었지만 정상 오탐 등
  증가로 전체 성능은 악화했다. 이 부분집합을 보고 클래스별 crop을 바로 선택하지 않는다.

원본+실제 ROI를 나란히 놓은 오답 표본 4장(각 12칸)을 확인했다.
무작위 표본과 높은 확률로 틀린 표본을 분리했으며 일부 사진은 중복된다.
정상 오탐에는 발바닥 주변·털·피부 결 등이, 놓침에는 흐린 ROI가 관찰됐다.
이는 촬영 특성 관찰이며, 사진만으로 라벨 오기나 질환 유무를 판정하지 않았다.

검증 전체를 실제 입력과 같은 384px ROI로 변환해 확인한 연관성:

| 범위 | 특징 | 오답 중앙값 | 정답 중앙값 | 특징이 클수록 오답일 AUROC |
|---|---|---:|---:|---:|
| 정상 A7 | 선명도 | .001016 | .000124 | .769 |
| 정상 A7 | 가는 결 지표 | .025644 | .009522 | .782 |
| A2 | 선명도 | .000581 | .001901 | .302 |
| A2 | 가는 결 지표 | .021069 | .032190 | .332 |

정상에서는 선명한/결이 많은 쪽, A2에서는 반대로 흐린/결이 적은 쪽에서 오류가 많다.
과거 화질 연관성과 방향이 맞는다. 결 지표는 털 검출기가 아니고, 관찰적 AUROC는
인과·통계적 유의성·증강 효과를 증명하지 않는다. 부위/개체 등의 교란을 통제하지 않았다.
사진 단위 탐색이며 같은 개체의 여러 사진을 독립 실험으로 해석하지 않는다.

## 다음에 할 일의 우선순위

1. **기존 채택 설정의 복원 여부 확인이 우선.** 새 기법으로 포장하지 않는다.
   이번 파일럿은 photometric·backbone LR 배율·warmup·EMA가 빠진 별도 학습법이다.
   `protocol.cfg`에 기본값이 남아 있어도 실제 runner는 EMA/warmup/배율을 사용하지
   않는다. 특히 실제 백본 LR은 3e-4로, moderate의 9e-5와 다르다.
2. 다음 학습을 한다면 **같은 고정 ROI에서 photometric 유무만 비교하는 복원 확인**을
   우선한다. 과거 STEP6은 이미 효과 기록이 있지만 현재 분할·ROI에서의 효과는 미확인이다.
   clean F1뿐 아니라 동일 검증 사진의 흐림 교란 전후 F1/AUROC/recall/specificity를
   같이 저장한다. 검증 증강 강도·표본·epoch 비교 규칙을 실행 전에 고정한다.
   LR·EMA·기간까지 동시에 바꾸면 무엇의 효과인지 분리할 수 없으므로 별도 단계로 둔다.
3. 사진 판독은 **라벨/ROI 검수용 목록**으로 진행한다. 모델 오답이라는 이유로
   라벨을 바꾸거나 검증 사진을 삭제하지 않는다. 전문가 검수 결과가 있어야 정제 판단 가능.
4. 새 전체 데이터 학습·실제 사용자 구도 평가가 아직 남아 있다. 파일럿의 성능이
   전체 학습의 상한은 아니며, 반대로 데이터 확대가 개선을 보장하지도 않는다.

이 분석에서는 추가 GPU 학습을 실행하지 않았다. 교란 추론도 아직 실행하지 않았으므로
이번 모델의 화질 의존성을 개입 실험으로 확인한 것으로 표시하지 않는다.
