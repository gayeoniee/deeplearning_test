## 2. 세션이 끊겨도 이어받기 (resume)

```
매 에폭 끝    ──▶  체크포인트 저장 (모델 가중치 + 옵티마이저 + 에폭 번호)
재시작        ──▶  마지막 체크포인트 찾아서 그 다음 에폭부터
```

핵심은 **"어디에" 저장하느냐**입니다. Kaggle 의 `/kaggle/working` 은 세션이 끝나면
사라지므로, `env.persist_root()` 가 환경별로 살아남는 위치를 골라줍니다.

여기에 **로짓 캐시(logit cache)** 도 붙였습니다. 검증 추론 결과를 저장해서,
재시작할 때 같은 계산을 다시 하지 않습니다. 단 **설정이 바뀌면 캐시가 무효**여야
하므로 지문(fingerprint)을 같이 저장합니다 — 안 그러면 옛날 결과를 새 실험 결과인 척
보게 됩니다. (`tests/test_resume.py` 52개 검사)

## 5. ★ 노트북 셀은 `git pull` 로 안 바뀝니다

**오늘 배운 것 중 가장 구조적인 것입니다.**

Kaggle/Colab 에 `.ipynb` 를 한 번 Import 하면, 그 셀들은 **다시 Import 하기 전까지
그대로**입니다. 첫 셀에서 `git pull` 을 해도 갱신되는 건 `src/` 뿐이고,
**셀 안에 직접 쓴 코드는 안 바뀝니다.**

그래서 규칙을 만들었습니다:

> **바뀔 수 있는 로직은 전부 `src/` 에 둡니다. 노트북 셀은 호출만 합니다.**

이 규칙에 따라 옮긴 것:

| 옮긴 것 | 어디로 |
|---|---|
| 품질 정지선 (실험을 멈출지 말지) | `src/gates.py` |
| 비교 실험 판정 규칙 | `src/experiments.py` |
| 1단계 크롭 선택 규칙 | `src/crop.py` (Day 4 에서) |

그리고 안전장치로, 첫 셀의 `MY_NOTEBOOK_VERSION` 이 `config.NOTEBOOK_VERSION` 과
다르면 **경고를 띄웁니다** → 다시 Import 하라는 신호.

## 6. 품질 게이트 재보정

`gates.py` 는 "이 실험 결과가 쓸 만한가" 를 판정합니다. 처음엔 기준 미달이면
전부 멈추게 했는데, **무인 실행(Save & Run All)을 죽여버렸습니다.**

그래서 2단계로 나눴습니다:

| 등급 | 뜻 | 동작 |
|---|---|---|
| **STOP** | 파이프라인이 깨짐 (누수, 크롭 없음, 랜덤 수준 점수) | 멈춤 |
| **WANT** | 목표 미달이지만 결과 자체는 유효 | 경고만 |

"목표 0.55 인데 0.53 나옴" 은 **결과**지 고장이 아닙니다. 멈추면 안 됩니다.

버그도 하나 잡았습니다 — 게이트가 **차이의 부호를 무시**해서 좋아진 걸 나빠졌다고
경고하고 있었습니다.

## 7. 오늘의 실측 — 파인튜닝 강도

인프라 말고 실제 실험이 하나 있었습니다.

> 📘 **파인튜닝(fine-tuning)이란**: ImageNet 등으로 미리 학습된 백본(backbone)을
> 가져와서, 우리 데이터로 **이어서** 학습시키는 것. 이때 백본을 얼마나 세게
> 움직일지가 선택지입니다. 보통 백본은 학습률(lr)을 낮게 줍니다 — 이미 잘 배운 걸
> 망가뜨리지 않으려고.

| 설정 | 백본 lr | 2단계 macro-F1 |
|---|---|---:|
| 기존 | ×0.1 | 0.4864 |
| **`moderate`** | **×0.3** | **0.5514** |

**+0.065.** 백본을 너무 안 움직이고 있었던 겁니다. 피부 병변은 ImageNet 사진과
꽤 달라서, 백본도 좀 더 배워야 했습니다.

같은 실행에서 잰 나쁜 소식도 있습니다: **배율 교란(scale perturbation) 하락 30.7%.**

> 📘 **배율 교란이란**: 학습이 끝난 모델에게 **같은 사진을 크기만 바꿔서** 보여주고
> 점수가 얼마나 떨어지는지 재는 검사입니다. 보호자는 멀리서도 가까이서도 찍으니까요.
> ⚠️ `multi-scale`(여러 배율로 **학습**)과 반대 방향입니다. 이건 **시험**입니다.

30.7% 하락은 배포 불가 수준입니다. 이게 Day 3~4 의 숙제가 됩니다.
