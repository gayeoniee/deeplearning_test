# Day 2 — 2026-08-20 (목) 파인튜닝 강도를 올렸더니 +0.065

오늘 실험은 하나입니다. **백본을 얼마나 세게 움직일 것인가.**
(나머지 커밋은 클라우드 실행 환경 정비라 로그에는 남기지 않습니다.)

---

## 1. 파인튜닝이 뭐고, 뭘 고르는 건가

**파인튜닝(fine-tuning)** 은 ImageNet 같은 큰 데이터로 미리 학습된
**백본(backbone)** 을 가져와서, 우리 데이터로 이어서 학습시키는 것입니다.
우리는 처음부터 이걸 하고 있었습니다. (전이학습 transfer learning 은 우산 개념이고,
파인튜닝은 그중 한 방식입니다.)

여기서 고를 게 하나 있습니다. **백본을 얼마나 세게 움직일지.**

```
백본 (미리 학습됨)          헤드 (우리가 새로 붙임)
─────────────────          ────────────────────
낮은 학습률 lr ×0.1?        정상 학습률 ×1.0
낮은 학습률 lr ×0.3?
```

보통 백본에는 낮은 학습률을 줍니다. 이미 잘 배운 걸 망가뜨리지 않으려고요.
그런데 얼마나 낮춰야 하는지는 데이터마다 다릅니다.

---

## 2. 실측

| 설정 | 백본 lr | 2단계 macro-F1 |
|---|---|---:|
| 기존 | ×0.1 | 0.4864 |
| **`moderate`** | **×0.3** | **0.5514** |

**+0.065.** 잡음 폭을 훨씬 넘는 차이입니다.

**해석**: 백본을 너무 안 움직이고 있었습니다. 피부 병변 사진은 ImageNet(고양이, 자동차,
의자 …)과 꽤 다릅니다. ImageNet 에서 배운 "가장자리, 질감, 색 덩어리" 는 여전히
쓸모 있지만, 그 위층은 우리 데이터에 맞게 다시 배워야 했던 겁니다.

프리셋은 `src/config.py` 에 넣었습니다. 노트북 셀에 숫자를 박아두면 나중에 못 바꿉니다.

```python
CFG(...) |> with_finetune("moderate")   # 백본 lr ×0.3
```

→ **이후 모든 실험은 `moderate` 기준입니다.**

## 3. 같은 실행에서 나온 나쁜 소식

**배율 교란(scale perturbation) 하락 30.7%.**

배율 교란은 학습이 끝난 모델에게 **같은 사진을 크기만 바꿔서** 보여주고 점수가 얼마나
떨어지는지 재는 검사입니다. 보호자는 멀리서도 가까이서도 찍으니까요.

⚠️ `multi-scale`(여러 배율로 **학습**시키는 기법)과 방향이 반대입니다.
이건 학습을 마친 모델을 배율 바꿔가며 **시험**하는 검사입니다.

30.7% 하락은 배포 불가 수준입니다. 점수가 아무리 좋아도, 보호자가 조금 멀리서 찍으면
3분의 1이 날아간다는 뜻이니까요. 이게 Day 3~4 의 숙제가 됩니다.
