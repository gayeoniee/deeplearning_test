## 전체 흐름

**AI Hub 는 해외 IP 다운로드를 차단**하므로 역할을 나눕니다.

```
━━━ 한국 PC (CPU 만) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 1  다운로드        prepare_local.py --chunk VL01
  STEP 2  스캔            (--chunk 중 자동 출력)  ← ★ 결과 공유 지점
  STEP 3  전처리          prepare_local.py --finalize
          패키징          prepare_local.py --package
                             │
                             │  dogskin_prepared.zip (2~5GB)
                             ▼  Google Drive 업로드
━━━ Colab (GPU) ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 4A 베이스라인      notebooks/03   ← 파이프라인 검증 게이트
  STEP 4B 모델 비교       notebooks/04
  STEP 5  평가·보정       notebooks/05   ← Grad-CAM 게이트
          배포 검토       docs/basics/10
```

> 노트북 00~02 는 **한국에 있는 서버에서 주피터로 작업할 때만** 씁니다.
> 로컬 PC + Colab 조합이면 `prepare_local.py` → 노트북 03 순서입니다.

## 단계별 상세

### ✅ STEP 0 — 리포 구축 (완료)

`src/` 모듈 15개, 노트북 6개, 문서 17개.
합성 데이터로 전 구간 검증 완료 (누수 0건, 기하 추출 100%, 학습 루프 동작).

### ⬜ STEP 1 — 데이터 확보

> 🚨 **AI Hub 는 해외 IP 다운로드를 차단합니다.** Colab/Kaggle 에서는 받을 수 없습니다.
> 한국 PC 에서 `python prepare_local.py --all` 로 다운로드+전처리까지 끝낸 뒤,
> 크롭본만 클라우드에 올려 학습합니다.
> → [`cautions/06`](cautions/06_해외IP_다운로드_차단_우회.md)

**한국 PC 에서:**
```bash
git clone https://github.com/gayeoniee/deeplearning_test.git
cd deeplearning_test && pip install -r requirements.txt
set AIHUB_API_KEY=발급받은키          # Windows cmd. Mac/Linux 는 export
python prepare_local.py --chunk VL01   # 25GB 필요, 30분~1시간
```

> Windows 에서 `pip` 이 없다고 나오면 `py -m pip`, `python` 대신 `py` 를 쓰세요.
> `aihubshell` 실행에는 Git Bash 가 필요합니다 → [`cautions/07`](cautions/07_Windows_로컬_환경_설정.md)

**명령**: `prepare_local.py --chunk VL01`
**읽을 문서**: [`cautions/01_데이터_라이선스와_재배포_금지.md`](cautions/01_데이터_라이선스와_재배포_금지.md)

### ⬜ STEP 2 — 데이터 확인 ★ 확인 지점

`scan.py` 가 스키마를 추론합니다. **여기서 멈추고 결과를 공유해주세요.**

확정해야 할 것:
- [ ] **무증상(정상) 데이터가 있는가** → 2단계 모델 가능 여부
- [ ] 개체ID 필드가 무엇인가 → 데이터 누수 방지
- [ ] polygon/bbox 키가 무엇인가 → ROI 크롭
- [ ] 병변 면적 분포 → 크롭 필요성 검증
- [ ] 클래스 불균형 정도 → 손실 가중치 설계

**노트북**: `01_데이터_스캔_EDA.ipynb`
**읽을 문서**: [`basics/02_이미지는_어떻게_숫자가_되나.md`](basics/02_이미지는_어떻게_숫자가_되나.md)

### ⬜ STEP 3 — 전처리

순서: 매니페스트 → 중복 제거 → **개체 단위 분할** → ROI 크롭 3종

통과 조건:
- [ ] `split.verify()` 통과 (누수 0건)
- [ ] `crop.preview_with_box()` 로 좌표 정확성 눈으로 확인
- [ ] 개체당 평균 이미지 수 ≥ 1.5

**노트북**: `02_전처리_매니페스트.ipynb`
**읽을 문서**: [`cautions/02_데이터_누수_가장_치명적인_함정.md`](cautions/02_데이터_누수_가장_치명적인_함정.md) ← 필독

### ⬜ STEP 4A — 베이스라인 + 크롭 비교

ResNet50 으로 파이프라인 검증 → 크롭 3종 비교 → 최적 크롭 확정

**게이트**: `macro-F1 > 0.25` (랜덤은 0.167)
못 넘으면 모델이 아니라 **데이터를 다시 보세요.**

**노트북**: `03_학습_베이스라인.ipynb`
**읽을 문서**: [`basics/03`](basics/03_CNN_직관으로_이해하기.md), [`basics/04`](basics/04_전이학습과_파인튜닝.md), [`basics/05`](basics/05_학습루프_옵티마이저_스케줄러.md), [`basics/06`](basics/06_과적합_정규화_데이터증강.md)

### ⬜ STEP 4B — 최신 모델 비교

timm 6종 (ResNet50 / EffNetV2-S / ConvNeXt V2 / Swin V2 / EVA-02 / SigLIP2) + 앙상블

**노트북**: `04_학습_최신모델_비교.ipynb`
**읽을 문서**: [`basics/09_ViT와_최신_백본_지도_2026.md`](basics/09_ViT와_최신_백본_지도_2026.md)

### ⬜ STEP 5 — 평가 · 보정 · 안전장치

온도 스케일링 → 거절 임계값 → **Grad-CAM 게이트** → holdout 최종 평가

**게이트**: CAM–병변 정렬도 `median_lift ≥ 1.3`
못 넘으면 정확도와 무관하게 **재작업**입니다.

**노트북**: `05_평가_보정_GradCAM.ipynb`
**읽을 문서**: [`basics/07`](basics/07_평가지표_의료AI_관점.md), [`basics/08`](basics/08_확률보정과_임계값_결정.md), [`cautions/03`](cautions/03_의료AI_안전설계_원칙.md)

## 목표 성능 (현실적 기준)

| 지표 | 목표 |
|---|---|
| 6종 macro-F1 (개체 단위 분할) | **0.70 ~ 0.80** |
| 모든 클래스 recall | ≥ 0.5 |
| A5·A6 (위험 병변) recall | 가능한 한 높게 |
| 1단계 정상/이상 recall | ≥ 0.95 |
| 보정 후 ECE | < 0.10 |

> ⚠️ 개체 단위 분할에서 **0.95+ 가 나오면 누수를 의심**하세요.
> 축하할 숫자가 아니라 검증해야 할 숫자입니다.
