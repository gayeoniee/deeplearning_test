분할을 감사해서 범위를 고정했습니다:

| | |
|---|---:|

| 이미 파일럿 검증에 썼던 것 제외 | −394장 → **6,183장** |
| 그중 **파일럿 검증에 나온 그룹의 다른 사진** | **6,026장** |
| 파일럿 검증에도 안 나온 그룹 | **157장뿐** |

> ⚠️ **평가 사진은 늘었지만 모델 선택에서 독립적이지 않습니다.**
> `animal_id` 는 대리 식별자이고 **근접 중복 검사는 미실시**입니다
> (SHA 동일 중복 제거와는 다른 일).
> **holdout 5,727장은 안 열었습니다.**

## 사전에 고정한 평가 조건

1. 고정 ROI, 384px letterbox 그대로
2. 같은 입력에 Gaussian blur **sigma=2, kernel=13**, reflect padding
3. 같은 크기 ROI 를 오른쪽·아래로 **변 길이의 20%** 이동, 영상 경계에서 제한

두 모델에 **같은 사진·같은 변환**, 문턱 .5 고정. 마지막 공통 epoch 5.

⚠️ 위치 이동은 **병변을 보존하도록 제한하지 않습니다** — 전체에서 6,171장의 창이
실제로 움직이고 **2,634장에서 주석 일부가 창 밖으로** 나갑니다.
**단일 방향·단일 강도의 합성 조건**이라 실제 사용자 입력을 대표하지 않습니다.

로컬 표본은 6,183장에서 클래스 비율을 유지해 미리 뽑은 **700장 / 129그룹**
(seed 20260909 · A1 83 / A2 56 / A3 121 / A4 24 / A5 14 / A6 26 / A7 376).
**오답이나 모델 점수를 보고 고르지 않았습니다.**
그룹 단위 paired bootstrap 2,000회는 **평가 표본의 불확실성**만 요약합니다 —
학습 seed 반복이나 외부 독립 검증을 대신하지 않습니다.
