## ① 수의학 표준 축 — 우리 묶음에 **사전 근거**가 생겼습니다

STEP 28 에서 저는 *"A2+A3 는 문서가 인정한 게 아니라 남은 것"* 이라고 적었습니다.
표준 문헌을 찾아보니 **그보다 나은 근거**가 있었습니다.

수의피부과의 표준 축은 **primary / secondary** 입니다:

| | |
|---|---|
| **primary** (병이 직접 만든 것) | macule · papule · plaque · wheal · vesicle · **pustule** · **nodule** |
| **secondary** (그 뒤에 생긴 것) | **collarette** · scar · excoriation · **erosion** · **ulcer** · fissure · **lichenification** · callus |
| **둘 다 됨** | **scale · crust · 색소 변화** (원인에 따라) |

우리 6종 대입:

```
A1 구진·플라크   → primary            A4 농포        → primary
A6 결절·종괴     → primary (>1cm)     A5 미란·궤양   → secondary
A2 비듬·각질·잔고리 → 잔고리 secondary / 비듬·가피 '둘 다'   → mixed
A3 태선화·색소침착  → 태선화 secondary / 색소침착 '둘 다'   → mixed
```

**두 가지가 우리 4군을 지지합니다.**

**ⓐ A2 와 A3 가 똑같이 애매합니다.** 둘 다 `mixed` — secondary 이거나 '둘 다 됨'
입니다. 출처가 *"secondary 는 여러 primary 에서 나올 수 있어 **진단 가치가 낮다**"*
고 적습니다. **A2+A3 를 한 통에 넣는다는 건 "덜 진단적인 둘"을 묶는 것**이라,
사후 정당화가 아니라 근거입니다.

**ⓑ A6 를 따로 둔 것이 표준과 맞습니다.** papule ≤1cm / **nodule >1cm** —
그 1cm 가 교과서 경계입니다.

⚠️ **저는 수의사가 아닙니다.** 위는 표준 문헌과 우리 데이터를 맞춰본 것이고,
*"A2 와 A3 를 한 이름으로 불러도 되는가"* 는 **수의사 확인이 필요합니다.**

### ★ 개(canine) 한정 자료가 더 직접적입니다

일반 피부과가 아니라 **개 피부과** 문헌을 다시 찾으니 이렇게 적혀 있습니다:

> *"Secondary lesions in canine dermatology include **erosions, ulcers, crusts,
> epidermal collarettes, hyperpigmentation and lichenification**."*

**A2(가피·잔고리) · A3(색소침착·태선화) · A5(미란·궤양)가 한 줄에 같이** 있습니다.
그리고 A3 의 두 성분에 대해:

> *"lichenified skin **frequently is also hyperpigmented**"*
> *"태선화와 색소침착은 **만성 경과**에서 같이 나타난다"*

**태선화와 색소침착이 같이 간다** — A3 라는 클래스 자체가 임상에서 한 덩어리로
쓰인다는 뜻입니다.

### 그래서 4군을 이렇게 다시 씁니다

| 묶음 | 축 | 뜻 |
|---|---|---|
| **융기·발진** (A1·A4) | primary, **표면보다 솟은 것** | 병이 지금 만들고 있는 것 |
| **결절·종괴** (A6) | primary, **>1cm · 더 깊은 층까지** | **감별이 필요** — 유일하게 이름을 지켜야 하는 것 |
| **표면 변화** (A2·A3) | mixed/secondary, **표피가 쌓이거나 두꺼워짐** | 병변이 지나간 흔적 · 만성 변화 |
| **미란·궤양** (A5) | secondary, **표피가 소실됨** | 얕게 벗겨짐(미란) / 더 깊이 패임(궤양) |

secondary 를 다시 가르는 선은 **"표피가 쌓이는가, 소실되는가"** 입니다.

> ### 🔴 2026-09-10 정정 — 위 표의 축 이름 셋이 틀렸었습니다
>
> 수의학 근거를 다시 대조하면서 **세 곳을 고쳤습니다.** 판정(4군 채택)은
> 그대로이고 **근거 서술만** 바뀝니다.
>
> | 전에 적었던 것 | 왜 틀렸나 | 지금 |
> |---|---|---|
> | 융기·발진 = `primary, ≤1cm` | **플라크(plaque)는 보통 >1cm** 입니다. A1 에 플라크가 들어 있으니 묶음 전체를 `≤1cm` 로 부르면 틀립니다 | `표면보다 솟은 것` |
> | 표면 변화 = `장벽 온전` | **표피잔고리는 농포가 터진 뒤** 남는 것이고 가피도 표면이 손상된 뒤 생깁니다 — "온전" 이 아닙니다 | `표피가 쌓이거나 두꺼워짐` |
> | 미란·궤양 = `2차 감염 위험` | 그건 **정의가 아니라 뒤따르는 위험**입니다. 핵심은 표피(미란)·더 깊은 조직(궤양)의 **소실** | `표피가 소실됨` |
>
> ★ **`1cm` 경계 자체는 여전히 맞습니다** — `papule ≤1cm / nodule >1cm` 라는
> 교과서 경계는 **A6 를 따로 둔 근거**로 그대로 섭니다. 틀렸던 것은 그것을
> *"A1·A4 전체 = ≤1cm"* 로 **확장한 표현**입니다.
>
> ⚠️ **`config.py` 는 ②③ 을 이미 고쳐놨는데 이 표에 안 따라왔습니다**
> (커밋 `e71c474`, *"기저막 파괴가 아니라 표피 소실"*).
> **정정이 한 곳에만 들어가고 사본에 안 따라간 것** — 이 리포가 촬영 가이드
> 밴드에서 이미 당한 모양입니다. *값을 복사한 곳끼리 비교하지 말고 출처와
> 비교하세요.*
>
> ⚠️ **A6 는 "종양" 이 아니라 "감별이 필요" 입니다.** 큰 결절·종괴에는
> 염증성 결절·낭종·깊은 감염·양성 종양이 모두 들어갑니다. 크기만으로 양성·악성을
> 못 가립니다 — `URGENCY_HINT["A6"]` 가 *"종양 감별 필요"* 인 것은 그래서 맞습니다.

**A2+A3 를 한 통에 넣는 것은 "덜 진단적인 secondary 를 묶는 것"** 이라는 뜻이
됩니다. 처음에 제가 *"남은 것"* 이라고 적었던 자리에 **축이 생겼습니다.**

⚠️ 다만 **A2·A3 는 깨끗한 secondary 가 아닙니다** — 가피와 색소침착은 원인에

## ② 앙상블 — 값을 재고 나서 **권고를 바꿨습니다**

STEP 31 의 69.8% 는 **3팔 앙상블** 값이었습니다 (노트북 11 이 앙상블만 쟀습니다).
릴리스 단독이면 얼마인지 안 재고 있었는데, 이제 쟀습니다:

| 묶음 | **릴리스 단독** | 3팔 앙상블 | 앙상블 값어치 |
|---|---:|---:|---:|
| 6종 이름 | **26.9%** | 41.4% | **+14.6%p** |
| 문서가 인정한 병합만 | 33.7% | 50.2% | +16.5%p |
| **★ 계열 4군 (권고)** | **59.4%** ✅ | 69.8% | **+10.4%p** |
| 형태 계열 3군 | 60.5% | 70.8% | +10.4%p |

**계열 4군에서 릴리스 단독도 59.4% 로 문턱(50%)은 넘습니다** (하향 3.3%).
그래서 처음엔 *"앙상블은 필요 없다"* 고 적었는데 — **비용을 안 재고 한 말이었습니다.**

### ★★ 정정 — "추론 3배" 는 제가 **안 재고 한 말**이었습니다

3팔이라고 3배가 아닙니다. 셋 중 둘이 **4.4배 작은 모델**입니다:

```
convnextv2_base  87.7M   ← 릴리스 (지금 서빙)
effnetv2_s       20.2M   ← 추가
effnetv2_s       20.2M   ← 추가
```

배포와 같은 조건(**CPU**, 스레드 4개, 사진 1장)에서 실측:

| | 릴리스 단독 | 3팔 앙상블 | 배수 |
|---|---:|---:|---:|
| 2단계만 | 633ms | 911ms | **1.44배** |
| **전체 파이프라인** (1단계 141ms 포함) | **774ms** | **1052ms** | **1.36배** |
| 파라미터 메모리 | 0.34GB | 0.50GB | +0.16GB |

**3배가 아니라 1.36배입니다.** 사진 한 장에 **+278ms**. 방금 사진을 찍은
사람에게 0.77초가 1.05초가 되는 것이라 **체감이 안 되는 구간**입니다.

⚠️ 배포가 **CPU** 라는 걸 확인하고 잰 값입니다 (`pyproject.toml` 의
`pytorch-cpu` 인덱스). GPU 시간으로 재면 뜻이 없습니다.

### 그래서 D2 의 답을 **바꿉니다 — 앙상블을 씁니다**

앞 판에서 저는 *"추론 3배를 치를 이유가 없다"* 고 적었습니다. **비용을 안 재고
한 말이었습니다.** 재고 나니 판단이 달라집니다:

| | |
|---|---|
| 얻는 것 | 커버리지 **+10.4%p** — 100명 중 **10명**에게 더 말할 수 있습니다 |
| 주는 것 | **+278ms** (1.36배) · **+0.16GB** · 체크포인트 2개 더 배포 |
| 덤 | **교란에도 더 강합니다** — 배율 하락 23.5→24.4%, **위치 17.9→15.2%** (STEP 26) |

**+278ms 로 10%p 를 사는 것**이고, 게다가 위치 교란은 오히려 좋아집니다.
치를 만한 값입니다.

⚠️ 남는 비용은 **유지보수** 쪽입니다 — 두 팔(`effnetv2_s` × 2)은 STEP 16
릴리스에 없습니다. 채택하면 릴리스에 넣고 같은 검사를 거치게 해야 합니다.
`export_release` 에 실험 이름 둘을 더하는 일이고, 빠뜨리면
`tests/test_calibration_wiring.py` 가 잡는 그 종류의 사고가 납니다.

⚠️ 반대로 **6종 이름을 켜기로 하면 앙상블이 필수**입니다 — 릴리스 단독 26.9% 는
닫음 문턱(30%) **아래**입니다. 앙상블이 41.4% 로 올려놓습니다.

★ 규칙성 하나: **굵게 말할수록 앙상블의 몫이 줄어듭니다** (+16.6 → +10.4 → +7.5%p).
앙상블이 메우는 건 *세밀한 구분*이고, 굵게 말하면 그 구분이 애초에 필요 없습니다.
