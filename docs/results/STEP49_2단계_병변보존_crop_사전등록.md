# STEP 49 — 2단계 병변 보존 crop 파일럿 · **사전등록** (2026-09-10, 결과 전)

> 이 문서는 **돌리기 전에** 씁니다 (작업 규칙 2). 결과가 나오면 아래 "실측" 절에
> 숫자만 붙이고, 위의 문턱·하한선·관문은 **고치지 않습니다.**

## 질문

2단계(병변 6종)에서 **병변 보존 random ROI**(`safe`)가 **고정 ROI**(`fixed`)보다
**위치 교란에 강하면서** clean 성능·계열 4군·A6 를 안 깎는가.

## 왜 지금 2단계인가 — 사용자 관찰 (2026-09-10)

1단계에서 `safe` 는 **두 번 졌습니다** (STEP 45 −, STEP 48 macro-F1 −0.110).
STEP 48 이 남긴 가설은 *"`safe` 는 병변을 보존하는데 **정상 사진엔 보존할 병변이
없어** 두 클래스의 크롭 분포가 갈리고, 모델이 구도를 배운다"* 였습니다.

사용자 질문: *"정상을 빼고 해보는 건? 1단계 통과했다고 치고 2단계에는 병변만
넘어왔다 가정하면?"* — **맞는 초점입니다.**

- 2단계에는 그 비대칭이 **성립할 수 없습니다** — 모든 사진에 병변이 있습니다
- 2단계의 알려진 약점이 **위치 교란 하락 32.2%** (STEP 16 holdout) 입니다 —
  `safe` 가 노리는 것이 정확히 그 축입니다
- 크롭 다양성이 2단계에서 값을 한 전례가 있습니다 (STEP 25, `m2.5`+`f320` 앙상블 +0.030)
- `--task stage2` 는 **한 번도 안 돌렸습니다** (`docs/experiment_history_audit.md`).
  STEP 4B 의 shift 증강은 **저장된 크롭** 위에서였고 같은 실험이 아닙니다

## 설계

| | |
|---|---|
| 데이터 | `safe-crop-pilot` 패키지(STEP 44)에서 **A7 제외** — train **10,177** / val **2,040** (A1 375 · A2 689 · A3 601 · A4 147 · A5 102 · A6 126). 청크 TL01 61% · TL02 28% · VL01 10% |
| 분할 | 패키지 그대로 (fold 0 · 개체 단위). **holdout 0장 — 안 엽니다** |
| 팔 | `fixed`(대조군): bbox 5% 여유 정사각 ROI(최소 320px) 가운데 / `safe`: 같은 ROI ×1.0~1.25, **병변을 다 담는 범위 안**에서 위치 무작위 (`src/roi_data.py`, STEP 45 와 같은 정의) |
| 모델 | `tf_efficientnetv2_s.in21k_ft_in1k` · 6클래스 head · 384px letterbox · **같은 초기값·같은 seed**, 두 팔 번갈아 |
| 학습 | AdamW 3e-4 · cosine(5 epoch 지평) · class-weighted CE · label smoothing 0.1 · flip/color 만 (STEP 45·46 과 같음) |
| 검증 | **둘 다 고정 ROI**. 매 epoch val 전체를 **두 번**: clean + **shift**(같은 ROI 를 변 길이의 **20%** 오른쪽·아래로, 경계에서 제한 — STEP 47 과 같은 정의) |
| 예산 | 캐글 T4 · `--hours 0.9` · 5 epoch. epoch 경계에서 이어받기 (`stage2_crop_pilot_resume.zip`) |

⚠️ **배포 백본(convnextv2_base)이 아닙니다.** 이 파일럿은 *"확대 실험을 할 가치가
있나"* 까지만 답합니다. 배포 모델을 바꾸는 판정은 전체 데이터·holdout 에서 따로 합니다.

⚠️ shift 는 **병변을 보존하도록 제한하지 않습니다** — 일부 주석이 창 밖으로 나갑니다.
단일 방향·단일 강도의 합성 조건이고 실제 사용자 입력을 대표하지 않습니다 (STEP 47 과 같은 단서).

## 문턱 · 하한선 · 관문 — 돌리기 전에 못 박음

**주 지표: shift 하락률** = (clean macro-F1 − shift macro-F1) / clean macro-F1, **마지막 공통 epoch**.

| | 값 | 근거 |
|---|---|---|
| **하한선** | `fixed` 팔 자신의 shift 하락률 | 같은 학습·같은 val·같은 초기값 — 아무것도 안 바꾼 것 |
| **후보 문턱** | `safe` 하락률이 `fixed` 보다 **5%p 이상 작다** | 교란 검사 잡음 ±5%p (CLAUDE.md) — 그 아래는 구분 불가 |
| 관문 1 | clean macro-F1: `safe − fixed ≥ −0.02` | 같은 설정 재실행 잡음 ±0.016 (STEP 12·13) |
| 관문 2 | **계열 4군 정확도**(6종 확률 합 → argmax): `safe − fixed ≥ −0.01` | 화면이 말하는 단위. ⚠️ **커버리지가 아닙니다** — 1단계 확률이 없어 여기서는 못 잽니다 |
| 관문 3 | A6 recall: `safe − fixed ≥ −0.03` | n=126 이라 잡음이 문턱보다 큽니다(±0.05 안팎) → **크게 나쁘면 기각** 용도이지 "통과" 를 증명하지 못합니다 |

판정 문장은 셋 중 하나만 씁니다:
- **후보** — 후보 문턱 통과 + 관문 셋 통과 → 전체 데이터·convnextv2_base 확대 실험을 사전등록
- **구분 불가** — 하락률 차이 0~5%p → 단일 seed 로는 더 못 말함. seed 반복이 다음
- **기각** — 하락률이 안 줄거나 관문 하나라도 미달

같이 찍되 관문으로 안 쓰는 것: A4 recall · A4→A1 비율 · A5 recall · shift 에서의 A6 recall.

| 길 | 무엇 | 필요한 관문 |
