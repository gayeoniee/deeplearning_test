# STEP 53 — 2단계 병변 보존 창, 배포 팔 하나를 갈아 끼우는 확대 실험 · 사전등록 (2026-09-13 확정, 결과 전)

> 2026-09-13 새벽 확정 — STEP 52 가 기각된 뒤(같은 표본 37.5% vs 34.0%), 남은 마지막 사전등록 갈래입니다. 캐글 무료 T4(주 30h 중 STEP 52 가 7.3h). 과금 0.

## 질문

STEP 49 파일럿(작은 모델·1만 장)에서 본 *"창을 흔들어 배우면 위치 강건성 +25%p, clean −0.02"* 가
**배포 팔 하나를 실제로 갈아 끼웠을 때 보호자 조건 커버리지**(작업 규칙 7)로 이어지는가.

## 왜 이 설계인가 — 예산과 데이터가 정합니다

- 캐글엔 원본이 없고 **`m2.5` 크롭 13GB**(`dogskin-m25`) 만 있습니다. 그 크롭은 bbox 중심에 2.5배 창이라 병변이 항상
  중앙 40% 상자 안 → 원본 없이도 "병변을 담는 범위에서 창 흔들기" 가 됩니다 (`src/safe_window.py`).
- convnextv2_base 전체 재학습은 T4 로 며칠 — 불가. **배포 3팔 중 `stage2_effnetv2_s_m2.5`(20M)** 하나를 같은 데이터로
  다시 배워 **그 자리에 끼우고** 3팔 커버리지를 재는 것이 한 세션(12h)에 들어가는 유일한 배포 검증입니다
  (STEP 23: effnetv2_s 전체 데이터 2판 9.1h, best epoch 4/7).

## 설계

| | |
|---|---|
| 데이터 | 캐글 `dogskin-m25` + `dogskin-manifest-365k`, 2단계 뷰(A1~A6, holdout 제외) — 노트북 06 과 같은 분할 |
| 팔 | `fixed`: 지금 배포 `stage2_effnetv2_s_m2.5` 학습법 그대로(대조군 = 재학습 없이 **배포 가중치 그대로** 씀, 예산 절약) / **`safe`**: 같은 레시피 + 학습 크롭을 `sample_window_in_crop`(변 0.42~1.0 · 중앙 병변 상자 보존 · 위치 무작위)으로 |
| ⚠️ 정의 차이 | 파일럿 `safe` 는 bbox 기준 ×1.0~1.25. 여기는 **크롭 전체까지** 넓힘 — 배포 입력이 사진 전체(포화)라서. 파일럿과 직접 비교 불가, 그래서 관문은 파일럿 값이 아니라 아래 |
| 학습 | effnetv2_s · 384 · `moderate` · photometric 없음(2단계는 STEP 6 대로) · 5 epoch(best 4/7 이었음) · T4 fp16 · epoch 경계 재개 |
| 판정 | `tools/detect_coverage.py --release <safe 팔로 바꾼 3팔>` — 같은 표본(fold 0 2,500+586) · **`user` 조건**(사진 전체 포화)과 `label` 조건 둘 다 |
