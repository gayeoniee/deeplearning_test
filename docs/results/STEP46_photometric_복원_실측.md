## 바꾼 것은 **하나**뿐입니다

두 팔 다 **고정 ROI**. `photo` 팔만 letterbox 뒤에 과거 `photometric` 연산자를
겁니다 — CLAHE .2 / blur .3 / noise .25 / JPEG .3 (`src.data` 프리셋과 같은 값).
**LR·EMA·기간은 안 건드렸습니다.**

> ★ `fixed` 팔의 예측이 [STEP 45](STEP45_ROI_crop_비교_실측.md) 의 ROI 파일럿과
> **모든 epoch 에서 정확히 동일**합니다 — 대조군이 진짜 같은 대조군이라는 확인입니다.

## 사전등록한 판정 기준

돌리기 전에 노트북 첫 셀에 박아뒀습니다:

> *"clean 은 비슷하거나 조금 낮고, **blur1/blur2 에서 photo 가 앞선다**"*

`photometric` 의 원래 효과는 **화질 지름길 차단**이었습니다 (STEP 6: 흐림 하락
−38.5%p, AUROC 는 그대로). **clean 점수만 보면 값어치가 안 보입니다.**

## 결과 (마지막 공통 epoch 5)

| 지표 | fixed | **photo** | 차이 |
|---|---:|---:|---:|
| clean macro-F1 | .851192 | **.856830** | +0.56%p |
| clean AUROC | .919625 | **.932973** | +.013348 |
| 이상 recall (문턱 .5) | **.815196** | .806373 | **−0.88%p** |
| 정상 specificity | .888776 | **.909694** | +2.09%p |
| **흐림 sigma1 F1** | .822075 | **.857519** | **+3.54%p** |
| **흐림 sigma2 F1** | .745505 | **.849494** | **+10.40%p** |
| 흐림 sigma2 AUROC | .868294 | **.927200** | +.058906 |
| **clean → sigma2 하락** | **10.57%p** | **0.73%p** | **하락이 거의 사라짐** |

흐림은 같은 검증 전체에 건 tensor Gaussian kernel 13, reflect padding 입니다.

> ★ **사전등록한 예측 그대로입니다.** clean 은 붙어 있고 흐림에서 갈립니다.
> 주된 성과는 clean 상승이 아니라 **합성 흐림에 대한 취약성 완화**입니다.

## 읽는 법

### 1. "전부 좋아졌다" 가 아닙니다

**clean 이상 recall 은 −0.88%p 로 조금 낮아졌습니다.** specificity 가 오른 만큼
문턱 근처가 옮겨간 것으로 보입니다. 1단계는 *놓치지 않는 것*이 우선이므로
이 줄은 **그냥 두면 안 되고 다음 실험에서 같이 봐야** 합니다.

### 2. epoch 을 골라 말하면 안 됩니다

- `photo` 의 clean F1 은 **epoch 1~3 에서 오히려 낮고** 4~5 에서 높습니다
- sigma2 F1 은 epoch 2 를 빼고 1/3/4/5 에서 `photo` 가 높습니다
  → ***"모든 epoch 에서 일관되게 우세"* 는 틀린 말입니다**
- 각자의 최고: fixed epoch 3 (.855238) / photo epoch 4 (.860614, AUROC .938034).
  **서로 다른 epoch 끼리의 차이는 참고값**입니다
- 다만 **epoch 4 끼리 맞춰 봐도** clean .853901 → .860614,
  sigma2 .768067 → .842997 로 같은 방향입니다 —
  **효과가 epoch 5 한 점에서만 나온 게 아닙니다**

### 3. blur 숫자는 재계산한 값이 아닙니다

clean 예측 10개 파일은 4,000장 ID·라벨을 대조하고 F1/AUROC 를 **재계산**했습니다.
**blur 는 저장된 history 기준**입니다 — ZIP 에 blur 개별 예측이 없어 재추론도
독립 재계산도 안 했습니다.

## 판정

**`photometric` 을 후속 실험의 기준 설정에 포함합니다.** 다음 학습에서 유지합니다.

⚠️ 단일 seed · 같은 검증셋 탐색입니다. **실사용자 사진이나 독립 holdout 성능을
입증하지 않습니다.** 배포 모델을 자동 교체하지 않습니다.
보관 후보는 `photo_best.pt` (clean F1 선택 규칙 기준 epoch 4).

## ⚠️ 학습률 복원은 **자동으로 다음 순서가 아닙니다**

이력 감사에서 *"backbone LR 배율도 빠졌다"* 를 같이 짚었지만, 근거를 다시 보니
**1단계에서는 뚜렷한 개선이 없었습니다**:

| STEP4A | 1단계 | 2단계 |
|---|---|---|
| 2차 | AUROC .8031 → **.8100** (기록상 오차 범위) | — |
| 3차 | **.8020** | F1 .4865 → **.5514** |

**`+0.065` 는 2단계에서 *기간 연장과 함께* 얻은 값**이라 학습률 단독 효과로
분리할 수 없습니다. → 지금 학습률을 낮추는 실험의 직접 근거가 아닙니다.
