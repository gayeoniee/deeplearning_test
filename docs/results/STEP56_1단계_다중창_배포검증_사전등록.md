> STEP 55 가 프록시 1단계 지표에서 통과한 뒤, **배포로 가기 위한 세 관문**을 돌리기 전에 못 박습니다. 전부 추론만(재학습 0), 로컬.
> 채택 점수는 STEP 55 의 둘 중 **`mean`(3×3 평균)** 을 주로 하고 `top3` 는 같이 찍습니다.

## ① 2단계 3팔 커버리지 (보호자 조건, `tools/detect_coverage.py --stage1-multiwin`)

같은 표본(fold 0 2,500 + 586). 1단계 점수만 사용자 중심 3×3 평균으로 바꾸고 2단계는 지금대로.
커버리지는 확신도(`p1 × p(계열)`) 순위로 정해지므로 문턱과 무관합니다.

| | 값 |
|---|---|
| **관문** | `s1mw_mean_user2 − user ≥ −2%p` (커버리지를 내주지 않을 것). 오르면 기록 |
| 찍기만 | `top3` · 창 셋 평균 2단계와의 조합 · 라벨 네모 2단계 |

## ② 문턱 재산정 (val, `tools/stage1_multiwindow_split.py --split val`)

평균 점수는 창 하나 점수보다 낮게 깔리므로 배포 문턱 0.1466 이 안 맞습니다. 배포 문턱과 같은 규칙 — **라벨 중심 조건에서 target recall 0.95** —
로 val 표본 5,000장(seed 7)에서 `label_mw_mean` / `label_mw_top3` 문턱을 뽑습니다. 같은 표본에서 창 하나 문턱도 다시 뽑아 배포값(0.1466)과
가까운지 봅니다(도구 검증).

## ③ holdout 1회 (`--split holdout --n 5000`, 문턱은 ②에서 가져옴)

⚠️ holdout 을 엽니다 — 이 도구가 다섯 번째입니다(05·06·07·12 + 이 도구). 결과를 보고 문턱·설계를 고치지 않습니다.

| | 값 | 근거 |
|---|---|---|
| **관문 A (상한 조건 유지)** | 라벨 중심 `label_mw_mean` AUROC ≥ `label_single` AUROC − 0.01, recall(각자 문턱) ≥ single − 0.01 | 라벨 네모 조건(holdout 0.9304)이 깨지면 안 됨 |
| **관문 B (보호자 조건 개선)** | 사용자 흉내 중심(±0.161): `user_mw_mean` recall ≥ `user_single` recall **+5%p**, 헛알림은 `user_single` **+2%p 이내** | STEP 55 의 헛알림 −5.5 가 holdout 에서도 "같은 헛알림에서 recall ↑" 로 나타나야 함 |
| 찍기만 | 위치 민감도(라벨 − 사용자 recall) single vs mw · top3 |

판정: 후보(①②③ 통과 → ④ 배선) / 구분 불가 / 기각.

## ④ 배선 (통과 시)

`agent.py` 1단계: 사용자 중심 3×3(간격 160px, 학습 픽셀 공간) 창 9개 → `p(이상)` 평균 → 새 문턱. 릴리스에 `stage1_threshold.json` 의
`multiwindow` 항목 추가(리비전 `v2`). 검사: 창 9개 좌표가 학습 창(`crop_window f320`)과 같은 규칙인지 · 문턱 배선 · `describe()` 에 창 수 노출.
비용: 1단계 추론 9배(effnetv2_s 320) — 배포 CPU 에서 실측해 SERVING.md 에 적음.

- **관문 A 미달** — 네모가 정확한 조건에서 AUROC **−0.097**, 같은 recall 에서 헛알림 +20.8%p. `mean`·`top3` 는 이대로 배포 불가.
- 사용자 흉내 조건은 방향이 맞습니다(AUROC +0.022, recall +10%p) — 그러나 헛알림 +12.7%p 라 관문 B(+2%p 이내)도 미달.
- **왜 프록시(STEP 55)와 다른가**: STEP 55 표에서도 `label_g3s160`(라벨 중심 3×3) 은 라벨 창 하나(0.8477)보다 **낮았습니다**(mean 0.7932) —
  제가 사용자 조건 개선만 보고 그 줄을 넘겼습니다. 다중 창 평균은 **중심이 어긋났을 때 이웃 창이 병변을 잡아 주지만, 중심이 정확할 때는
  병변 없는 이웃 창이 증거를 희석**합니다. 원본 사진(창 하나 AUROC 0.92)에선 희석 손실이 더 큽니다.
