# STEP 37 — 사람도, 모델도 네모를 못 줍니다

> STEP 36 이 *"사람은 네모 크기를 못 맞춘다"* 로 끝났습니다. 남은 길 둘을
> 재봤고 **둘 다 닫혔습니다.** 사전등록한 문턱은 하나도 안 옮겼습니다.

**2026-09-07 · 로컬 GPU(RTX 3050) · 학습 0회**

---

## ① 탭 — 점 하나만 받기 · **기각**

`f320`(1단계 크롭)은 **중심만** 씁니다. 크기를 아예 안 물어보면 *"뭘 기준으로
44%인지 모르겠다"* 가 설계에서 사라집니다. 그래서 **실제 탭 정확도**를 쟀습니다.

판정 기준은 **재기 전에** 박았습니다 — `TAP_ERROR_MAX = 0.10`. 근거는
시뮬레이션(기준선 `m2.5`+사용자 네모 = 0.3609):

| 탭 오차 | `f320` | 차이 |
|---:|---:|---:|
| 0.02 | 0.4521 | +0.091 (라벨 네모 수준 유지) |
| 0.05 | 0.4318 | +0.071 |
| **0.10** | **0.3830** | **+0.022** (잡음 ±0.016 위) |
| 0.161 (네모 중심) | 0.3363 | −0.025 |

### 실측 (40장, 사람이 직접, 건너뜀 0)

```
탭 오차 중앙값  0.111      (문턱 0.10)
10~90%         0.015 ~ 0.491
문턱 안         42.5%
```

**중앙값 0.111 > 0.10 → 기각.** 아슬아슬하지만 **문턱을 안 옮겼습니다.**

### ★ 그런데 분포가 갈라져 있습니다

| | |
|---|---|
| 25분위 | **0.028** — 아주 정확 |
| 75분위 | **0.328** — 완전히 빗나감 |
| **탭이 병변 안에 들어간 비율** | **47.5%** |

병변 크기와의 상관은 −0.179 로 약합니다. 작은 병변이 조금 더 어렵지만
(0.151 vs 0.105) 그게 주된 이유는 아닙니다.

> **경계가 뚜렷한 병변은 콕 찍힙니다. 번진 것(비듬·각질 · 태선화)은 못 찍습니다.**
> 그런 병변엔 사람이 답할 수 있는 **"중심" 이 애초에 없습니다.**

사용자의 말이 정확했습니다 — *"점으로 어떻게 찍어.. 무조건 범위로 가야 하는데"*.

## ② 모델이 제안하기 · **기각**

사람이 못 주면 **모델이 제안하고 사람은 판단만** 하면 됩니다. 고르는 건
만드는 것보다 쉬우니까요. 다만 제안이 자주 틀리면 *"아니요"* 가 반복돼
아무도 안 씁니다. **짓기 전에** 그 비율을 쟀습니다.

방법 — 1단계는 `f320`(320px 고정 창)으로 배웠으므로 **분류기를 그대로 창
탐지기로** 씁니다. 사진을 320px 창 9×9 로 훑어 창마다 '이상' 확률을 재고,
점수 가중 무게중심을 제안 위치로 냅니다.

⚠️ **Grad-CAM 이 아닙니다.** Grad-CAM lift 4.55(STEP 16)는 *"배경을 안 본다"*
는 뜻이지 네모를 뽑는 도구가 아닙니다. 여기서는 모델에 **학습 때 본 것과 같은
입력**만 먹였습니다.

### 결과 (300장, VL01)

| | 모델 제안 | 사람 |
|---|---:|---:|
| 배율 밴드 안 | **39.0%** | 10.0% |
| 위치 밴드 안 | **19.0%** | 12.5% |
| **둘 다** | **6.7%** | 5.0% |

**6.7% < 문턱 50% → 기각.**

★ 모델이 사람보다 **두 축 다 낫습니다** (배율은 4배). 그런데 둘이 같이
맞는 일이 드뭅니다. 크기비 중앙값도 1.78배로 사람(2.80배)보다 낫지만 여전히
밴드(0.71~1.67) 밖입니다.

⚠️ **고정 창의 한계도 있습니다** — 320px 창으로는 그보다 작은 것을 짚을 수
없습니다. 배율 39% 중 일부는 자극 크기가 우연히 맞은 몫입니다.

## 그래서 지금까지 닫힌 것

| 길 | 결과 |
|---|---|
| 사용자가 **네모 크기** | ❌ 병변 크기와 무관 (상관 −0.05) |
| 사용자가 **점 위치** | ❌ 중앙값 0.111 · 병변 안 47.5% |
| **모델이 제안** | ❌ 둘 다 밴드 안 6.7% |
| 기본값 44% 조정 | ❌ 어떤 고정값도 5.6~59.6% 를 못 덮음 |
| `f320` 전환 | ❌ 하락 차이 +0.021 < 0.03 |

> ★ **입력 쪽에서 고치는 길이 다 막혔습니다.**
> 남은 것은 **모델을 잡음에 튼튼하게** 만드는 쪽입니다 (STEP 38).
