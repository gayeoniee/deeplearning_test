## ★ 화질 지름길은 **실재했습니다**

가장 큰 발견입니다. 사진을 흐리게 했을 때:

| | 원본 | r=1 | r=2 | r=3 | 하락 |
|---|---:|---:|---:|---:|---:|
| `resnet50` / `default` | 0.7430 | 0.6437 | 0.3861 | **0.3316** | **55.4%** |
| `resnet50` / `photometric` | 0.7487 | 0.7479 | 0.7243 | 0.6224 | **16.9%** |
| `effnetv2_s` / `default` | 0.7663 | 0.6877 | 0.5561 | 0.4015 | 47.6% |
| `effnetv2_s` / `photometric` | 0.7705 | 0.7663 | 0.7524 | 0.6627 | **14.0%** |

**기존 1단계 모델은 사진을 흐리게 하면 성능이 반토막 났습니다** (0.7430 → 0.3316).
balanced-acc 는 0.5000 — 즉 **동전 던지기로 무너집니다.**

크롭 감사에서 본 그 신호가 원인이었습니다:

| | 선명도 중앙값 | 흐린 사진 |
|---|---:|---:|
| A7 무증상(정상) | **50** | 57.2% |
| 병변 6종 | 274 | 23~50% |

정상 사진이 계통적으로 흐리고, 모델이 **"흐리면 정상"** 을 배웠습니다.
그 신호는 배포에 없습니다 — 보호자는 아픈지 모르는 채로 찍으니까요.

### photometric 이 그걸 막았습니다

`resnet50` 기준 **55.4% → 16.9% (−38.5%p)**, `effnetv2_s` 는 47.6% → 14.0%.
두 백본에서 같은 방향·비슷한 크기로 나왔습니다 — 우연이 아닙니다.

**그리고 val AUROC 를 깎지 않았습니다** (resnet50 에서 오히려 +0.0029).

### 2단계와 정반대입니다 — 예측대로

| | photometric 효과 |
|---|---|
| 2단계 (병변 6종) | macro-F1 **−0.03** ❌ 질감이 곧 라벨이라 흐림이 답을 지움 |
| **1단계 (정상/이상)** | AUROC **+0.0029**, 흐림 하락 **−38.5%p** ✅ |

같은 약이 다른 환자에게는 들었습니다. **"2단계에서 실패했으니 1단계도 안 된다"
고 넘겼으면 못 찾았을 것**입니다.

## ⚠️ val AUROC 최고를 안 골랐습니다

`effnetv2_s` / `default` 가 0.8359 로 가장 높습니다. 그래도 안 고릅니다.

| | AUROC | 흐림 하락 |
|---|---:|---:|
| `effnetv2_s` / `default` | 0.8359 | **47.6%** |
| `effnetv2_s` / `photometric` | 0.8284 | **14.0%** |
| 차이 | −0.0075 (잡음 ±0.01 **안**) | −33.6%p (잡음 ±5%p **밖**) |

**val 점수로 고르다 holdout 에서 무너진 게 STEP 5 의 실패였습니다** (0.8143 → 0.7412).
지름길을 쓰는 모델은 val 에서 높게 나옵니다 — 그게 지름길의 정의입니다.
같은 실수를 반복하지 않으려면 **잡음 안의 AUROC 우위보다 잡음 밖의 견고성**을 봅니다.

→ `experiments.stage1_report()` 의 채택 규칙을 "val AUROC 최고" 에서
**"두 축의 판정을 합친 조합"** 으로 고쳤습니다. 이제 val 최고와 채택안이 다르면
그 사실과 이유를 출력합니다.

## 관찰 — 기록해 둘 것

**① `effnetv2_s` 가 훨씬 빨리 과적합합니다**

| | train loss (처음→끝) | val loss | best epoch |
|---|---|---|---:|
| `resnet50` / default | 0.5725 → 0.5137 | 0.5651 → 0.5910 | 4 |
| `effnetv2_s` / default | 0.5277 → **0.2922** | 0.5489 → **0.6536** | 4 |

train loss 가 절반 아래로 떨어지는데 val loss 는 오릅니다. 서브셋 55% 라
더 그럴 수 있지만, **풀 학습에서는 정규화를 더 걸어야 할 수 있습니다**
(drop_path, weight_decay, 또는 조기 종료 patience 축소).

`photometric` 은 이걸 완화합니다 (train 0.6004 → 0.4079 로 완만) — 증강이
정규화 역할을 겸하는 흔한 현상입니다.

**② `effnetv2_s` 의 첫 에폭 loss 가 3.29 였습니다**

이진 분류에서 무작위가 0.693 인데 3.29 는 초반 폭주입니다. 1에폭에 0.76 으로
회복했지만 정상은 아닙니다. 같은 실행에서 `lr_scheduler.step() before
optimizer.step()` 경고도 **effnetv2_s 에서만** 나왔습니다 — AMP 의 GradScaler 가
fp16 오버플로로 첫 스텝들을 건너뛴 것입니다.

→ 풀 학습에서 lr 3e-4 를 낮추거나 warmup 을 늘리는 걸 고려하세요.
지금은 회복했으므로 결과는 유효합니다.
