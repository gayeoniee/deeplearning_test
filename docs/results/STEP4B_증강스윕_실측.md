잡음과 효과를 구분 못 했던 문제를 여기서 없앴습니다.

## 읽는 법

**6종이 default 와 구분되지 않습니다.** 잡음 폭(±3%p) 안입니다.
유일하게 잡음을 넘은 신호는 **부정적인 것 하나** — `zoom_both` 가 하락을 4%p 키웠습니다.

### 1. 축소 증강, 세 번째 실패

| 시도 | 해상도 | 하락 | |
|---|---|---:|---|
| `scale_robust` (확대만) | 224px | 31.6% | ❌ |
| `zoom_both` (축소 포함) | 224px | 27.7% | ❌ |
| **`zoom_both`** | **384px** | **default 대비 +4.0%p** | ❌ **악화** |

384px 에서는 0.5x 조건에 짧은 변 219px 이 남아 "가르칠 정보가 있다"고 봤는데,
가르쳤더니 **더 나빠졌습니다.** 축소 증강이 정보를 지우는 대가가 얻는 불변성보다 큽니다.

### 2. `photometric` — 화질 지름길을 막으려다 신호를 지웠습니다

macro-F1 이 **0.4918 → 0.4613 (−0.0305)** 로 7종 중 유일하게 뚜렷하게 떨어졌습니다.
하락폭은 그대로였고요.

가설은 이랬습니다 — 정상 사진 선명도 중앙값 39 vs 병변 271 이니, 흐림을 넣으면
모델이 화질로 맞히는 지름길이 막힐 것이다. **결과는 반대입니다.**
흐림·노이즈가 지운 건 지름길이 아니라 **병변 질감 그 자체**였습니다.
비듬 알갱이와 농포 경계는 우리가 실제로 쓰는 신호입니다.

### 3. 폭 좁히기 — 방향은 보이지만 크기가 없습니다 (멘토 피드백 1번)

`rrc_scale` 하한을 세 점으로 찍었습니다:

```
0.70 (default)  17.6%
0.85 (narrow)   15.9%   ← 최저
0.92 (narrower) 16.5%   ← 다시 상승
```

**0.85 근처에서 꺾이는 모양**이 나왔습니다. 예고한 세 경우 중 "중간이 최적" 에 해당합니다.
다만 **전체 차이가 1.7%p 로 잡음 안**이라 "최적점을 찾았다" 고 말할 수 없습니다.
방향만 있고 크기가 없습니다.

한 가지 흥미로운 부수 소득: **`narrower` 만 최악 조건이 확대(2x)로 바뀌었습니다.**
폭을 좁히면 축소 취약성이 완화되고 확대가 병목이 된다는 뜻인데, 이것도 잡음 안입니다.

### 4. ⚠️ 서브셋 하락률을 풀 데이터에 대입하면 안 됩니다

| | macro-F1 | 배율 하락 |
|---|---:|---:|
| 풀 데이터 (03) | 0.5697 | 25.9% |
| 서브셋 55% (이번) | 0.4918 | 17.6% |

**서브셋이 오히려 덜 떨어집니다.** 직관과 반대인데, 이유는 하락률이 **기준 점수에
대한 상대값**이기 때문입니다. 약한 모델은 원래 낮으니 잃을 것도 적습니다.

→ 스윕의 **순위**는 쓸 수 있지만 **절대값**은 못 씁니다.
   앞으로도 이 표의 15.9% 를 "목표 15% 에 근접" 으로 읽으면 안 됩니다.
