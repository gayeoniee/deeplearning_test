# 04. 전이학습과 파인튜닝

> **읽는 시점**: STEP 4(학습) 전
> **중요도**: ★★★ 이 시리즈에서 가장 실용적인 문서

---

## 왜 우리가 딥러닝을 할 수 있는가

정직하게 말하면, 강아지 피부 사진 몇만 장으로 신경망을 **밑바닥부터** 학습시키면
잘 안 됩니다. 수백만 장은 있어야 하거든요.

그런데 됩니다. **전이학습** 덕분입니다.

```
ImageNet 1400만 장으로 학습된 모델
   = "선, 질감, 패턴, 형태"를 이미 볼 줄 아는 상태
        ↓
   마지막 분류층만 갈아 끼우고
        ↓
   우리 데이터 몇만 장으로 미세조정
        ↓
   ✅ 잘 됨
```

**비유**: 의대를 졸업한 사람에게 수의피부과를 가르치는 것과,
고등학생에게 처음부터 가르치는 것의 차이입니다.
해부학·병리학 기초는 이미 있으니 전문 분야만 얹으면 됩니다.

---

## 코드 한 줄

```python
model = timm.create_model(
    "convnextv2_base.fcmae_ft_in22k_in1k",
    pretrained=True,      # ← 이게 전부입니다
    num_classes=6,        # ← 마지막 층만 6개로 교체
)
```

`pretrained=True` 가 하는 일:
1. 사전학습 가중치를 다운로드 (첫 실행 시)
2. 백본에 로드
3. 원래 1000개(ImageNet) 출력이던 마지막 층을 **버리고**
   6개 출력의 새 층을 **랜덤 초기화**로 생성

## timm 모델 이름 읽는 법

```
convnextv2_base.fcmae_ft_in22k_in1k
└────┬─────┘ └┬─┘ └──────┬────────┘
  구조      크기      사전학습 이력
```

| 부분 | 의미 |
|---|---|
| `convnextv2` | 모델 구조 |
| `base` | 크기 (tiny < small < base < large < huge) |
| `fcmae` | Masked Autoencoder 로 자기지도 사전학습 |
| `ft_in22k` | ImageNet-22k(1400만 장)로 파인튜닝 |
| `in1k` | 다시 ImageNet-1k 로 파인튜닝 |

**실무 팁**: `in22k` 가 들어간 가중치가 대체로 더 좋습니다.
더 많고 다양한 데이터를 봤으니까요.

## 핵심 기법 1: 층별 학습률 (Layer-wise LR)

**문제**: 백본은 이미 잘 학습돼 있는데, 새 헤드는 랜덤입니다.
같은 학습률로 돌리면?

- 랜덤 헤드가 만드는 **큰 오차 신호**가 백본까지 흘러들어가
- 애써 학습된 백본의 지식을 **망가뜨립니다** (catastrophic forgetting)

**해결**: 백본은 천천히, 헤드는 빠르게.

```python
cfg = CFG(lr=3e-4, backbone_lr_mult=0.1)
# 헤드 lr = 3e-4
# 백본 lr = 3e-5   (10배 느리게)
```

`src/models.py` 의 `param_groups()` 가 이걸 처리합니다:

```python
groups = {
    "head_decay":   {"lr": cfg.lr},                        # 3e-4
    "bb_decay":     {"lr": cfg.lr * cfg.backbone_lr_mult}, # 3e-5
    ...
}
```

## 핵심 기법 2: Warmup

학습 **초반 몇 스텝** 동안 lr 을 0에서 목표까지 서서히 올립니다.

```python
cfg = CFG(warmup_epochs=2)
```

이유는 같습니다. 학습 시작 직후 랜덤 헤드의 오차가 가장 큰데,
그때 큰 lr 로 때리면 백본이 무너집니다. 워밍업으로 충격을 완화합니다.

## 핵심 기법 3: weight decay 예외

```python
no_decay = p.ndim <= 1 or n.endswith(".bias")
```

BatchNorm/LayerNorm 파라미터와 bias 에는 weight decay 를 **걸지 않습니다.**
이들은 정규화 통계를 담당하는데 0으로 끌어당기면 그 역할이 왜곡됩니다.
관례이자 실측으로 검증된 방법입니다.

## 전략 3가지 — 언제 뭘 쓰나

### ① Linear Probing (백본 완전 동결)

```python
models.freeze_backbone(model, freeze=True)
```

백본은 고정, 마지막 층만 학습.

- ✅ 빠름 (역전파가 마지막 층까지만)
- ✅ 과적합 거의 없음
- ✅ 데이터 수백~수천 장이면 이게 최선
- ❌ 성능 상한이 낮음

**언제**: 데이터가 아주 적을 때, 혹은 빠른 기준선이 필요할 때.

### ② Full Fine-tuning (전체 학습) ← 우리의 기본

```python
# 아무것도 얼리지 않고, 백본 lr 만 낮춤
cfg = CFG(lr=3e-4, backbone_lr_mult=0.1)
```

- ✅ 성능이 가장 좋음
- ❌ 데이터 적으면 과적합
- ❌ 느리고 메모리 많이 씀

**언제**: 데이터 수천 장 이상. **우리 프로젝트는 수만 장이니 여기 해당.**

### ③ 점진적 해동 (Gradual Unfreezing)

```python
# 1~2 에폭: 헤드만
models.freeze_backbone(model, True)
train.fit(model, ..., CFG(epochs=2))

# 이후: 전체
models.freeze_backbone(model, False)
train.fit(model, ..., CFG(epochs=15))
```

먼저 헤드를 안정화시킨 뒤 전체를 풉니다. 안전하지만 번거롭습니다.
Warmup 이 비슷한 효과를 내서 요즘은 덜 씁니다.

## 도메인 갭 — 우리가 마주한 진짜 문제

ImageNet 은 **고양이, 자동차, 나무** 사진입니다.
우리는 **강아지 피부 확대 사진**입니다. 꽤 다르죠.

```
ImageNet:  전체 물체, 다양한 배경, 일상적 거리
우리:      피부 클로즈업, 털·병변 질감, 배경 거의 없음
```

이 차이를 **도메인 갭**이라고 합니다. 그래도 전이학습은 통합니다:

- **낮은 층**(선, 질감, 색 경계)은 도메인 무관 → 거의 그대로 유용
- **높은 층**(고양이 얼굴 감지기)은 쓸모없음 → 파인튜닝으로 재학습

그래서 **깊은 층일수록 더 많이 바뀌어야** 합니다.
정석대로면 층별로 lr 을 다르게 주는 LLRD(Layer-wise LR Decay)를 쓰지만,
우리는 단순화해서 백본/헤드 2단계만 나눴습니다. 대부분 충분합니다.

> 💡 도메인 갭이 클수록 **더 많은 에폭**과 **더 높은 백본 lr** 이 필요합니다.
> 성능이 정체되면 `backbone_lr_mult` 를 0.1 → 0.3 으로 올려보세요.

## 파운데이션 모델 (2026년의 선택지)

최근에는 ImageNet 분류가 아니라 **자기지도 학습**으로 만든 백본이 강합니다:

| 모델 | 학습 방식 | 특징 |
|---|---|---|
| **DINOv3** | 자기지도 (라벨 없이) | 밀집 예측·분류 모두 강함 |
| **SigLIP 2** | 이미지-텍스트 대조학습 | 소량 데이터에서 특히 강함 |
| **EVA-02** | Masked Image Modeling | 정확도 상한 |

의료 영상 연구에서 "자연 이미지로 사전학습된 파운데이션 모델 + LoRA" 가
도메인 갭을 넘어 잘 전이된다는 보고가 여럿 있습니다.

**우리 노트북 04에 SigLIP2 가 포함된 이유**입니다.
데이터가 수만 장 규모라면 시도할 가치가 충분합니다.

## 흔한 오해 3가지

**❌ "pretrained=False 로 처음부터 배우는 게 우리 데이터에 더 맞을 것"**
거의 항상 틀립니다. 수십만 장 이상이 아니면 전이학습이 압도적입니다.
차이가 macro-F1 0.1~0.3 씩 납니다.

**❌ "사전학습 모델이 크면 클수록 좋다"**
데이터가 수만 장이면 base 급이 large 급을 이기는 일이 흔합니다.
큰 모델은 그냥 외워버리거든요. **실험으로 정하세요.**

**❌ "전이학습이니까 lr 을 아주 작게"**
너무 작으면 도메인 갭을 못 넘습니다. 백본이 ImageNet 상태 그대로 남죠.
기본값(헤드 3e-4, 백본 3e-5)에서 시작해 조정하세요.
