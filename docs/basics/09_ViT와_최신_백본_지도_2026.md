# 09. ViT와 최신 백본 지도 (2026)

> **읽는 시점**: STEP 4-B(최신 모델 비교) 전

---

## 큰 그림 — 지난 10년

```
2012  AlexNet          CNN 이 ImageNet 을 압도, 딥러닝 시대 개막
2015  ResNet           residual connection → 100층 이상 학습 가능
2019  EfficientNet     깊이/너비/해상도를 균형 있게 스케일링
2020  ViT              트랜스포머를 이미지에! "CNN 없어도 된다"
2021  Swin             ViT 에 계층 구조 도입 → 실용성 확보
2022  ConvNeXt         "CNN 도 ViT 기법 쓰면 이긴다" 반격
2023  DINOv2, EVA-02   자기지도 학습 백본이 강해짐
2024~ SigLIP2, DINOv3  파운데이션 모델 시대
```

**핵심 교훈**: "가장 최신 = 가장 좋음"이 아닙니다.
2026년 기준으로도 **ConvNeXt V2 같은 현대 CNN 이 ViT 와 대등하거나 우위**입니다.

---

## ViT — 이미지를 문장처럼 다루기

CNN 은 작은 필터를 미끄러뜨립니다. ViT 는 완전히 다르게 접근합니다.

```
224×224 이미지
   ↓ 16×16 패치로 자르기
14×14 = 196개 패치
   ↓ 각 패치를 벡터로 (= "단어")
196개 토큰
   ↓ 트랜스포머 (self-attention)
분류
```

### Self-attention 이 하는 일

각 패치가 **모든 다른 패치를 참조**해서 자기 표현을 갱신합니다.

```
"왼쪽 위 패치야, 오른쪽 아래 패치를 봐.
 거기도 비슷한 붉은 반점이 있네 → 이건 넓게 퍼진 병변이구나"
```

**CNN 과의 차이:**

| | CNN | ViT |
|---|---|---|
| 시야 | 처음엔 좁게, 깊어지며 넓게 | **1층부터 전체** |
| 가정 | "가까운 픽셀끼리 관련" (귀납 편향) | 가정 없음 |
| 데이터 요구량 | 적어도 됨 | **많이 필요** |
| 강점 | 국소 질감 | 전역 문맥, 넓게 퍼진 패턴 |

### 우리 문제에서는?

- **A2 비듬·각질**: 미세 질감 → **CNN 유리할 가능성**
- **A3 태선화**: 넓은 영역의 색·주름 변화 → **ViT 유리할 가능성**
- **A6 결절·종괴**: 형태 + 주변 대비 → 비슷

**답은 실험이 알려줍니다.** 노트북 04에서 둘 다 돌립니다.

> 💡 ViT 는 데이터가 적으면 CNN 에 밀립니다. 귀납 편향이 없어서
> "이미지란 이런 것" 을 데이터로부터 다 배워야 하거든요.
> 다만 대규모 사전학습 가중치를 쓰면 이 단점이 크게 완화됩니다.

## 우리 모델 라인업 해설

### ① ResNet50 — 기준선

```python
"resnet50.a1_in1k"    # 25M params
```

2015년 모델입니다. **왜 아직 쓰나?**
- 모든 논문·블로그가 이걸 기준으로 씁니다 → 비교 가능
- 빠르고 안정적 → 파이프라인 검증용으로 최적
- **이것보다 못 나오면 데이터에 문제가 있는 것**

### ② EfficientNetV2-S — 효율 챔피언

```python
"tf_efficientnetv2_s.in21k_ft_in1k"    # 21M params
```

- 파라미터 대비 성능이 매우 좋음
- 학습이 빠름 (V1보다 훨씬)
- **모바일 배포 1순위 후보** — 앱에 넣을 거라면 이쪽

### ③ ConvNeXt V2 — 현대 CNN, 우리의 유력 후보

```python
"convnextv2_base.fcmae_ft_in22k_in1k"    # 89M params
```

"ViT 가 잘 되는 건 트랜스포머 때문이 아니라 **학습 기법** 때문 아닐까?"
라는 질문에서 출발해, CNN 에 ViT 의 기법(큰 커널, LayerNorm, GELU 등)을
적용한 모델입니다. 결과적으로 ViT 와 대등하거나 더 좋습니다.

V2는 **FCMAE**(마스킹 자기지도 학습)로 사전학습해서 더 강해졌습니다.

> 💡 **피부 병변에 특히 기대되는 이유**: CNN 계열이라 질감 표현이 좋고,
> 큰 커널(7×7)로 넓은 맥락도 봅니다. 우리 문제의 두 요구를 다 만족합니다.

### ④ Swin V2 — 계층적 ViT

```python
"swinv2_base_window12to16_192to256.ms_in22k_ft_in1k"    # 88M
```

ViT 의 문제(모든 패치가 모든 패치를 봐서 계산량이 O(n²))를
**윈도우 안에서만 attention** 하고 윈도우를 옮겨가며 해결했습니다.
CNN 처럼 계층적이면서 ViT 의 장점을 유지합니다.

### ⑤ EVA-02 — 정확도 상한 확인용

```python
"eva02_base_patch14_448.mim_in22k_ft_in22k_in1k"    # 87M
```

Masked Image Modeling 으로 사전학습한 강력한 ViT.
ImageNet 벤치마크 최상위권입니다.

**단점**: 무겁습니다. 448px 원본은 T4 에서 버겁습니다.
우리 코드는 224/336 변형으로 fallback 합니다.

### ⑥ SigLIP 2 — 파운데이션 모델

```python
"vit_base_patch16_siglip_256.v2_webli"
```

이미지-텍스트 쌍 수십억 개로 학습된 백본입니다.
분류 라벨이 아니라 **자연어 설명**과 맞춰가며 배워서,
더 풍부하고 일반적인 표현을 갖습니다.

**소량 데이터 파인튜닝에서 특히 강한 편**이라 우리 규모에 맞을 수 있습니다.

---

## 파운데이션 모델 — 2026년의 새 흐름

| 모델 | 사전학습 | 특징 |
|---|---|---|
| **DINOv3** | 자기지도 (라벨 없이) | 분류·분할 모두 강함. 밀집 특징이 뛰어남 |
| **SigLIP 2** | 이미지-텍스트 | 다국어, 동적 해상도 |
| **MetaCLIP 2 / Perception Encoder** | 이미지-텍스트 | CLIP 후속 |

의료 영상 연구에서 "자연 이미지 파운데이션 모델 + LoRA 파인튜닝"이
도메인 갭을 넘어 잘 전이된다는 보고가 축적되고 있습니다.
(예: DINOv3 를 병리 이미지에 LoRA 로 적응)

### LoRA — 큰 모델을 싸게 파인튜닝

```
전체 파인튜닝: 89M 파라미터 전부 업데이트 → 메모리 폭발
LoRA:         작은 저차원 행렬만 학습 (1~2M) → 메모리 1/10
```

성능은 거의 같은데 메모리와 저장 공간이 훨씬 적게 듭니다.
Colab 에서 큰 모델을 돌려야 한다면 좋은 선택지입니다.
(우리 코드에는 아직 없습니다. 필요하면 `peft` 라이브러리 추가)

## 어떻게 고를까 — 실무 가이드

```
데이터 1천 장 미만
   → EfficientNetV2-S 또는 linear probing

데이터 1만 장 내외          ← 우리는 여기 근처
   → ConvNeXt V2 base, SigLIP2, EffNetV2-S 비교

데이터 10만 장 이상
   → EVA-02, ConvNeXt V2 large 까지 시도

모바일/실시간 배포
   → EfficientNetV2-S, MobileNetV4

최고 정확도가 목표, 자원 충분
   → 여러 모델 앙상블
```

**공통 원칙**: base 급 3~4개를 비교해보고, 이긴 것을 키우세요.
처음부터 large 를 쓰면 시간만 쓰고 과적합합니다.

## 앙상블 — 다양성이 핵심

```python
Ensemble([convnextv2, swinv2, effnetv2])    # ✅ 계열이 다름
Ensemble([convnextv2_s42, convnextv2_s43])  # ⚠️ 이득 작음
```

**서로 다른 방식으로 틀리는** 모델을 섞어야 효과가 큽니다.
CNN 과 ViT 는 실패 패턴이 다르므로 좋은 조합입니다.

보통 단일 최고 모델보다 macro-F1 **+1~3%p** 정도 얻습니다.

**대가**: 추론 시간이 N배. 서비스라면 이 비용을 감당할 수 있는지 판단하세요.

## timm 이름 다루기

timm 은 버전마다 모델 이름이 바뀝니다.

```python
from src import models
models.available()      # 이 환경에서 실제로 되는 것만 확인

import timm
print(timm.__version__)
timm.list_models("*convnext*", pretrained=True)
```

우리 `models.py` 는 이름이 없으면 fallback 을 순서대로 시도하고,
그것도 없으면 접두어가 같은 아무 모델을 잡습니다. 경고를 찍으면서요.

## 흔한 오해 3가지

**❌ "ViT 가 CNN 을 대체했다"**
아닙니다. 2026년에도 현대 CNN 은 경쟁력이 있고,
데이터가 적은 도메인에서는 오히려 유리합니다.

**❌ "파라미터가 많을수록 좋다"**
우리 데이터 규모에서는 base(≈90M)가 large(≈200M)를 이기는 게 흔합니다.

**❌ "SOTA 논문 모델을 쓰면 SOTA 성능"**
논문 수치는 ImageNet 기준입니다. 우리 도메인에서의 순위는 다를 수 있습니다.
**직접 비교하는 것 말고 방법이 없습니다.**
