## 왜 이미지에 특별한 구조가 필요했나

224×224×3 이미지를 그냥 펼쳐서 신경망에 넣으면?

```
입력 150,528개 → 첫 층 뉴런 1,000개
파라미터 = 150,528 × 1,000 = 1억 5천만 개  ← 첫 층에서만!
```

**문제 1: 파라미터 폭발.** 이 정도면 데이터 수십만 장으로도 못 채웁니다.

**문제 2: 위치 정보 상실.** 펼치는 순간 "이 픽셀 옆에 저 픽셀이 있다"는
공간 관계가 사라집니다. 병변은 **픽셀들의 국소적 패턴**인데요.

**문제 3: 이동에 취약.** 병변이 왼쪽 위에 있을 때와 오른쪽 아래에 있을 때를
완전히 다른 입력으로 봅니다. 같은 병변인데도요.

CNN 은 이 셋을 한 번에 해결합니다.

---

## 합성곱(Convolution) — 작은 도장 찍기

핵심 아이디어: **작은 필터(커널)를 이미지 전체에 미끄러뜨리며 찍는다.**

3×3 필터 하나를 예로 들면:

```
필터 (3×3):              이미지의 한 조각 (3×3):
 -1  -1  -1               10  10  10
 -1   8  -1        ×      10  90  10     →  8×90 - 8×10 = 640
 -1  -1  -1               10  10  10
                                            "가운데가 밝다!" = 점 감지
```

이 필터를 이미지 전체에 훑으면 **"밝은 점이 있는 위치"** 지도가 나옵니다.
농포(A4)나 구진(A1) 탐지에 딱 맞는 필터겠죠.

### 세 가지 문제가 어떻게 풀리나

**파라미터 폭발 →** 필터는 3×3×3 = 27개 파라미터뿐입니다.
이미지가 아무리 커도 필터 크기는 그대로.

**위치 정보 →** 3×3 이웃 픽셀끼리만 계산하니 공간 관계가 유지됩니다.

**이동 취약 →** 같은 필터를 **모든 위치에** 적용하니
병변이 어디 있든 같은 필터가 반응합니다. 이걸 **가중치 공유(weight sharing)** 라고 합니다.

### 중요한 사실

> **필터의 값(-1, 8 같은 숫자)은 사람이 정하지 않습니다.**
> 학습으로 알아서 정해집니다.

위 예시는 설명용이고, 실제로는 "어떤 필터가 A1~A6 구분에 도움이 되는지"를
경사하강법이 찾아냅니다. 이게 딥러닝이 피처 엔지니어링을 대체하는 방식입니다.

## 층을 쌓으면 생기는 마법: 계층적 특징

```
1층    →  선, 색 경계, 명암 변화        (모든 이미지에 공통)
2~3층  →  모서리, 곡선, 간단한 질감
4~6층  →  반복 패턴, 털 질감, 비늘 모양
깊은 층 →  "농포처럼 생긴 것", "궤양처럼 생긴 것"
```

각 층이 **이전 층의 출력을 재료로** 더 복잡한 걸 만듭니다.
레고 블록으로 점점 큰 구조물을 쌓는 것과 같습니다.

이게 **전이학습이 작동하는 이유**이기도 합니다.
ImageNet(고양이, 자동차, 나무...)으로 배운 1~3층의 "선·질감 감지기"는
강아지 피부에도 그대로 쓸 수 있거든요. 선은 어디서나 선이니까요.

→ [`04_전이학습과_파인튜닝.md`](04_전이학습과_파인튜닝.md)

## 수용 영역(Receptive Field)

층이 깊어질수록 **한 뉴런이 보는 원본 영역**이 넓어집니다.

```
1층 뉴런  → 원본 3×3 영역을 봄
2층 뉴런  → 원본 5×5 영역
3층 뉴런  → 원본 7×7
...
깊은 층    → 이미지 거의 전체
```

이게 왜 중요하냐면:

- **얕은 층**은 좁게 봐서 질감(A2 비듬·각질)에 강함
- **깊은 층**은 넓게 봐서 전체 형태(A6 결절·종괴)에 강함

우리 데이터에는 둘 다 있으니 **적당히 깊은 모델**이 필요합니다.

---

## 풀링(Pooling) — 크기 줄이기

```
MaxPool 2×2:
  1  3        →   6      (2×2 영역에서 최댓값만)
  6  2
```

- 계산량을 1/4로 줄이고
- 약간의 위치 변화에 둔감해집니다 (병변이 2픽셀 움직여도 결과가 같음)

요즘 모델은 풀링 대신 **stride 2 합성곱**(2칸씩 건너뛰며 훑기)을 많이 씁니다.
같은 효과인데 그 축소 방식마저 학습으로 정하기 때문입니다.

## 전체 구조

```
입력 (3, 224, 224)
   ↓ Conv + BN + ReLU        (64, 224, 224)   ← 채널↑ (필터 64개)
   ↓ Pool                    (64, 112, 112)   ← 해상도↓
   ↓ Conv + BN + ReLU        (128, 112, 112)
   ↓ Pool                    (128, 56, 56)
   ↓ ... 반복 ...
   ↓                         (2048, 7, 7)     ← 작지만 깊음
   ↓ Global Average Pool     (2048,)          ← 7×7 을 평균내 1개로
   ↓ Linear                  (6,)             ← 우리 클래스 수!
   ↓ Softmax                 확률 [0.1, 0.6, ...]
```

**패턴**: 해상도는 줄이고 채널은 늘립니다.
"어디에 있나"(공간)에서 "무엇이 있나"(의미)로 정보를 바꿔가는 과정입니다.

**마지막 Linear 층**이 우리가 바꿔 끼우는 부분입니다:

```python
timm.create_model("convnextv2_base", pretrained=True, num_classes=6)
#                                                     ^^^^^^^^^^^^^
#  ImageNet 1000 클래스용 층을 버리고 6 클래스용으로 새로 만듦
```

## BatchNorm — 실무에서 꼭 알아야 하는 것

```python
Conv → BatchNorm → ReLU
```

각 층의 출력을 **배치 단위로 평균 0, 분산 1로 정규화**합니다.

**왜 필요한가**: 층을 지나며 값의 분포가 계속 변하면 학습이 불안정합니다.
BN 이 매 층마다 분포를 되돌려주니 학습이 빠르고 안정적이 됩니다.

**실무에서 중요한 두 가지:**

1. **학습/추론 동작이 다릅니다.**
   학습 때는 배치 통계를, 추론 때는 학습 중 누적한 이동평균을 씁니다.
   → `model.train()` / `model.eval()` 을 **반드시** 제대로 호출해야 합니다.
   안 하면 추론 결과가 배치 구성에 따라 달라집니다.

2. **배치가 너무 작으면 망가집니다.**
   배치 2~4에서는 배치 통계가 불안정합니다.
   VRAM 이 부족하면 배치를 줄이는 대신 `grad_accum` 을 쓰세요:
   ```python
   cfg = CFG(batch_size=8, grad_accum=8)   # 실효 배치 64
   ```
   (다만 BN 통계는 여전히 8개 기준입니다. 그래서 요즘 모델은
   BN 대신 LayerNorm/GroupNorm 을 쓰는 추세입니다 — ConvNeXt 가 그렇습니다.)

## Dropout — 무작위로 뉴런 끄기

학습 중에 뉴런 일부를 랜덤하게 0으로 만듭니다.

```python
cfg = CFG(drop_rate=0.2)   # 20% 를 끔
```

**왜 도움이 되나**: 특정 뉴런에만 의존하지 못하게 강제합니다.
"이 뉴런이 없어도 맞혀야 해" → 여러 특징을 두루 쓰게 됨 → 일반화 향상.

**drop_path (Stochastic Depth)** 는 뉴런이 아니라 **층 전체**를 건너뜁니다.
깊은 모델(ConvNeXt, ViT)에서 더 효과적입니다.

```python
cfg = CFG(drop_path_rate=0.1)
```

> 💡 데이터가 적을수록 이 값들을 올리세요. 과적합이 심하면 0.3까지도.

## 흔한 오해 3가지

**❌ "필터는 사람이 설계한다"**
아닙니다. 전부 학습됩니다. 3×3 이라는 크기와 개수만 사람이 정합니다.

**❌ "CNN 은 이제 한물갔다, ViT 가 답이다"**
2026년 기준으로도 **ConvNeXt V2 같은 현대 CNN 은 ViT 와 대등하거나 우위**입니다.
특히 데이터가 수만 장 규모면 CNN 이 더 안정적인 경우가 많습니다.
질감이 중요한 피부 병변에서는 CNN 이 유리할 가능성도 있고요.
→ 노트북 04에서 둘 다 돌려 비교합니다.

**❌ "깊을수록 좋다"**
데이터가 적으면 깊은 모델은 외워버립니다.
ResNet50(25M) 이 ConvNeXt-Large(198M) 보다 나을 수 있습니다.
