# 01. 머신러닝과 딥러닝의 결정적 차이

> **대상**: 머신러닝은 해봤지만 딥러닝은 처음
> **읽는 시점**: 제일 먼저

---

## 이미 아시는 것부터

sklearn 으로 이런 걸 해보셨을 겁니다:

```python
X = df[["나이", "몸무게", "체온", "백혈구수"]]   # 사람이 고른 특징
y = df["질환여부"]
model = RandomForestClassifier().fit(X, y)
```

여기서 **가장 중요한 작업이 뭐였나요?** 모델 선택이 아니라 `X` 를 만드는 일,
즉 **피처 엔지니어링**이었을 겁니다. 좋은 특징을 찾으면 로지스틱 회귀도 잘 하고,
나쁜 특징이면 XGBoost 도 못 합니다.

---

## 딥러닝의 한 문장 요약

> **딥러닝은 특징을 사람이 만들지 않고, 모델이 스스로 찾게 하는 것입니다.**

우리 프로젝트로 예를 들면:

```
[머신러닝 방식]
  강아지 피부 사진
     ↓  사람이 코드로 계산
  "붉은 정도", "질감 거칠기", "경계 선명도", "색상 히스토그램"...
     ↓
  RandomForest → A1~A6

[딥러닝 방식]
  강아지 피부 사진 (픽셀 그대로)
     ↓
  신경망이 알아서 특징을 만들어냄
     ↓
  A1~A6
```

**왜 이미지에서는 딥러닝이 이겼나?**

"구진(A1)과 농포(A4)를 구분하는 특징"을 코드로 써보세요. 못 씁니다.
수의사도 말로 설명하기 어려운 걸 픽셀 연산으로 표현하는 건 사실상 불가능합니다.
그런데 사진과 정답 쌍을 수만 개 주면, 신경망은 그 규칙을 **스스로** 찾아냅니다.

---

## 그래서 뭐가 달라지나

| | 전통 ML | 딥러닝 |
|---|---|---|
| 사람의 주 업무 | **피처 엔지니어링** | **데이터 품질 + 학습 설계** |
| 필요 데이터 | 수백~수천 행 | 수천~수십만 장 (전이학습 쓰면 완화) |
| 학습 시간 | 초~분 | **시간~일** |
| 학습 장비 | CPU | **GPU 필수** |
| 결과 해석 | 특징 중요도 | Grad-CAM 등, 상대적으로 어려움 |
| 실패 원인 | 대개 특징 부족 | **대개 데이터 문제** |

### 가장 큰 심리적 차이: 실험 사이클

sklearn 은 `.fit()` 이 3초라 100번 시도해볼 수 있습니다.
딥러닝은 **한 번에 2시간**입니다.

그래서 습관이 바뀝니다:
- 아무거나 돌려보기 ❌ → **돌리기 전에 생각하기** ✅
- 결과 보고 판단 ❌ → **실패 조건을 미리 정하기** ✅
- 기록 안 함 ❌ → **모든 실험 기록** ✅ (`docs/cautions/05` 참고)

우리 노트북 03에 `assert macro_f1 > 0.25` 가 들어 있는 이유입니다.
무거운 모델로 3시간 태우기 전에, 가벼운 모델로 파이프라인이 살아있는지 먼저 봅니다.

## 그대로 통하는 것 (안심하세요)

머신러닝 지식의 대부분은 그대로 씁니다:

- **과적합/과소적합** — 개념 동일, 대응 수단만 다름 (dropout, 증강 등)
- **train/val/test 분할** — 동일. 오히려 **더** 중요 (`cautions/02`)
- **클래스 불균형** — 동일 (class weight, 샘플러)
- **평가 지표** — precision/recall/F1/AUROC 전부 동일
- **교차검증** — 동일 (다만 시간이 오래 걸려 덜 씀)
- **손실함수, 경사하강** — 로지스틱 회귀에서 이미 보신 것

## 신경망이 뭔지 30초 설명

로지스틱 회귀 아시죠?

```
y = sigmoid(w·x + b)
```

이걸 **여러 겹 쌓은 것**이 신경망입니다:

```
h₁ = ReLU(W₁·x  + b₁)      ← 1층
h₂ = ReLU(W₂·h₁ + b₂)      ← 2층
h₃ = ReLU(W₃·h₂ + b₃)      ← 3층
y  = softmax(W₄·h₃ + b₄)   ← 출력층
```

끝입니다. 진짜로 이게 전부입니다.

**핵심은 "겹쳐 쌓는다"는 것:**
- 1층은 단순한 것(선, 색 경계)을 봅니다
- 2층은 1층의 결과를 조합해 조금 복잡한 것(모서리, 무늬)을 봅니다
- 깊은 층은 아주 복잡한 것(병변 패턴)을 봅니다

**ReLU** 는 `max(0, x)` 입니다. 음수를 0으로 만드는 것뿐인데,
이게 없으면 아무리 층을 쌓아도 결국 하나의 선형 변환이 되어버립니다.
비선형성이 있어야 층을 쌓는 의미가 생깁니다.

**학습**은 로지스틱 회귀와 똑같이 "손실을 줄이는 방향으로 W 를 조금씩 옮기기"입니다.
다만 층이 많으니 **역전파(backpropagation)** 라는 방법으로
"각 층의 W 가 최종 오차에 얼마나 책임이 있는지"를 뒤에서부터 계산합니다.
연쇄법칙(chain rule) 그 자체입니다.

## 우리 프로젝트에서 실제로

```python
model = timm.create_model("convnextv2_base", pretrained=True, num_classes=6)
```

이 한 줄이 하는 일:
- 수십 개 층을 가진 신경망 구조를 만들고
- ImageNet 1400만 장으로 **미리 학습된 가중치**를 불러오고
- 마지막 분류층만 6개(A1~A6) 출력으로 갈아 끼웁니다

그리고 우리 데이터로 미세조정합니다. 이게 **전이학습**이고,
데이터가 수만 장뿐인 우리가 딥러닝을 쓸 수 있는 이유입니다.

→ [`04_전이학습과_파인튜닝.md`](04_전이학습과_파인튜닝.md) 에서 자세히

## 흔한 오해 3가지

**❌ "딥러닝이 항상 머신러닝보다 낫다"**
표 형태 데이터(tabular)에서는 **아직도 XGBoost/LightGBM 이 강합니다.**
딥러닝이 압도적인 건 이미지·음성·텍스트처럼 **구조가 있는 고차원 데이터**입니다.

**❌ "층을 많이 쌓을수록 좋다"**
데이터가 적으면 큰 모델은 그냥 외워버립니다(과적합).
우리 데이터 규모(수만 장)에서는 base 급이 large 급보다 나을 가능성이 높습니다.
그래서 노트북 04에서 **실험으로** 정합니다.

**❌ "데이터를 더 넣으면 해결된다"**
같은 강아지 사진 10만 장은 다른 강아지 1만 마리보다 못합니다.
**양보다 다양성**입니다. 그리고 라벨이 틀렸으면 양을 늘려도 소용없습니다.
→ 이 프로젝트가 중복 제거와 개체 단위 분할에 공을 들이는 이유입니다.
