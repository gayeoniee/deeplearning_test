# ⚠️ AI Hub 해외 IP 다운로드 차단

> **증상**: Colab/Kaggle 에서 `aihubshell -mode d` 실행 시
> ```
> Download failed with HTTP status 502.
> Error msg:
> AI 허브는 해외에서의 데이터 다운로드를 제한하고 있습니다.
> ```

---

## 무슨 일인가

AI Hub 는 **한국 IP 에서만 데이터 다운로드를 허용**합니다.
Google Colab 과 Kaggle 의 VM 은 미국·유럽·대만 등 한국 밖에 있어서 차단됩니다.

- 목록 조회(`-mode l`)는 됩니다 ← 그래서 처음엔 잘 되는 것처럼 보입니다
- **다운로드(`-mode d`)만 막힙니다**

코드로 우회할 방법은 없습니다. VPN 을 쓰는 것도 이용약관상 권하지 않습니다.

---

## 해결: 역할을 나눕니다

```
┌─────────────────────────┐        ┌─────────────────────────┐
│  한국 PC (내 컴퓨터)      │        │  클라우드 (Colab/Kaggle) │
│                         │        │                         │
│  · AI Hub 다운로드 ✅    │  zip   │  · 모델 학습 ✅          │
│  · 스캔                 │ ─────▶ │  · 평가·보정             │
│  · 전처리 (중복제거,     │ 2~5GB  │  · Grad-CAM             │
│    개체분할, ROI 크롭)   │        │                         │
│                         │        │                         │
│  GPU 불필요, CPU 만      │        │  GPU 필요                │
└─────────────────────────┘        └─────────────────────────┘
```

**핵심**: 전처리를 로컬에서 끝내면 **업로드할 용량이 1/5~1/10 로 줄어듭니다.**

```
원본 VL01.zip     21 GB
   ↓ ROI 크롭 (512px, jpg q92)
크롭본 + 매니페스트   2~5 GB   ← 이것만 올리면 됨
```

전처리는 **CPU 만 씁니다.** 노트북 컴퓨터로도 됩니다 (시간은 좀 걸립니다).

---

## 로컬 PC 에서 할 일

### 0. 준비

한국에서 실행 중인지 확인하세요. 회사 VPN 이 해외로 잡혀 있으면 똑같이 막힙니다.

```bash
git clone https://github.com/gayeoniee/deeplearning_test.git
cd deeplearning_test
pip install -r requirements.txt
```

> 💡 `torch` 설치가 오래 걸립니다. 전처리만 할 거면 GPU 버전이 아니어도 됩니다.
> 사실 전처리 단계는 torch 없이도 돌아갑니다 (Pillow, pandas, imagehash 만 있으면 됨).

### 1. API 키를 환경변수로

```bash
# Linux / Mac
export AIHUB_API_KEY="발급받은키"

# Windows (cmd)
set AIHUB_API_KEY=발급받은키

# Windows (PowerShell)
$env:AIHUB_API_KEY="발급받은키"
```

⚠️ 코드나 파일에 직접 쓰지 마세요.

### 2. 한 번에 실행

```bash
python prepare_local.py --all
```

또는 단계별로 (중간에 확인하며 가고 싶다면):

```bash
python prepare_local.py --download      # 21GB 받기
python prepare_local.py --scan          # 스키마 추론 ← 결과 공유해주세요
python prepare_local.py --preprocess    # 중복제거 → 개체분할 → 크롭
python prepare_local.py --package       # 업로드용 zip 만들기
```

디스크는 **50GB 정도** 여유를 두세요 (원본 21GB + 압축해제 + 크롭본).

### 3. 결과물

```
dogskin_prepared.zip     ← 이것만 올리면 됩니다
```

안에 들어있는 것:
- `crops/` — ROI 크롭 이미지 (학습에 실제로 쓰는 것)
- `manifests/` — 매니페스트 parquet (라벨, 개체ID, fold, holdout 정보 포함)
- `reports/` — 스캔 리포트

**원본 이미지는 안 들어갑니다.** 크롭본만 있으면 학습에 충분합니다.

## 클라우드에 올리기

### Kaggle (권장)

용량 제한이 넉넉하고, 노트북에 붙이면 **읽기 전용으로 빠르게 마운트**됩니다.
Google Drive 처럼 느리지 않습니다.

1. [kaggle.com/datasets](https://www.kaggle.com/datasets) → **New Dataset**
2. `dogskin_prepared.zip` 업로드
3. **⚠️ Visibility 를 반드시 `Private` 로** ← AI Hub 데이터는 재배포 금지입니다
4. 학습 노트북에서 → 우측 **Add Input** → 만든 데이터셋 선택
5. `/kaggle/input/<데이터셋이름>/` 에 마운트됩니다

노트북에서:
```python
import os, zipfile
os.environ["DOG_SKIN_WORK"] = "/kaggle/working/data/work"
with zipfile.ZipFile("/kaggle/input/<이름>/dogskin_prepared.zip") as z:
    z.extractall("/kaggle/working/data/work")
```

**Kaggle GPU**: 주 30시간 무료 (T4 ×2 또는 P100), 세션 12시간.
Colab 무료보다 학습에 유리합니다.

### Google Drive (2~5GB 라 무료 15GB 안에 들어가면)

1. Drive 에 zip 업로드
2. Colab 에서:

```python
from google.colab import drive
drive.mount("/content/drive")

import zipfile, os
os.environ["DOG_SKIN_WORK"] = "/content/data/work"
with zipfile.ZipFile("/content/drive/MyDrive/dogskin_prepared.zip") as z:
    z.extractall("/content/data/work")     # ← 반드시 로컬 디스크로 풀 것
```

> ⚠️ **Drive 에서 직접 이미지를 읽지 마세요.** 네트워크 마운트라
> 작은 파일 수만 개를 읽으면 학습이 10배 느려집니다.
> 반드시 `/content` 로 압축을 풀고 거기서 읽으세요.

## 자주 묻는 것

**Q. 로컬에 GPU 가 없는데 전처리 되나요?**
됩니다. 전처리는 전부 CPU 작업입니다 (JSON 파싱, 해시 계산, 이미지 크롭).
28,000장 기준으로 노트북 컴퓨터에서 30분~1시간 정도 예상합니다.

**Q. VPN 으로 한국 IP 를 쓰면 안 되나요?**
기술적으로는 될 수 있지만 권하지 않습니다. AI Hub 이용약관 위반 소지가 있고,
계정 제재 대상이 될 수 있습니다.

**Q. Training 데이터(340GB)도 이렇게 받을 수 있나요?**
로컬 디스크가 충분하다면 가능합니다. 다만:
- TL01 90GB + TL02 80GB = 170GB 다운로드
- 전처리 후 크롭본은 20~40GB → Kaggle 업로드는 가능 (Drive 는 불가)
- **먼저 VL01(21GB)로 파이프라인을 완성한 뒤** 성능이 부족하면 늘리세요.
  데이터를 늘리기 전에 크롭 방식·모델·증강을 먼저 최적화하는 게 효율적입니다.

**Q. 학교/회사 서버가 한국에 있는데 거기서 받아도 되나요?**
됩니다. GPU 까지 있다면 전 과정을 거기서 하는 게 제일 편합니다.
