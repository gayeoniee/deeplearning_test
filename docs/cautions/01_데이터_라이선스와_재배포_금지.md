# ⚠️ 데이터 라이선스와 재배포 금지

> **읽는 시점**: 데이터를 받기 전에.

---

## 핵심 3가지

1. **AI Hub 데이터는 재배포 금지입니다.** GitHub에 올리지 마세요.
2. **API 키는 계정 자격증명입니다.** 노트북·코드에 붙여넣지 마세요.
3. **활용신청 승인이 필요합니다.** 보통 1영업일.

---

## 1. 데이터를 커밋하면 안 되는 이유

AI Hub 데이터는 "이용약관에 동의한 개인이 승인받아 사용" 하는 구조입니다.
받은 사람이 다시 뿌리는 건 약관 위반이고, 이건 국가 예산으로 구축된 데이터라
문제가 생기면 계정 제재 대상입니다.

특히 이 데이터는 **실제 반려동물의 의료 이미지**입니다.
보호자가 병원에 제공한 정보라는 점도 기억하세요.

### 이 프로젝트의 방어

`.gitignore` 가 아래를 전부 막고 있습니다:

```gitignore
/data/            # 원본
*.jpg *.png       # 이미지 전부
*.parquet         # 매니페스트 (경로·메타데이터 포함)
*.pt *.onnx       # 모델 가중치
.env *apikey*     # 자격증명
```

> 💡 `.gitignore` 의 `/data/` 앞 슬래시가 중요합니다.
> `data/` 로 쓰면 `docs/data/` 까지 무시돼서 문서가 안 올라갑니다.

### 커밋 전 습관

```bash
git status --short       # 이미지가 섞여 있지 않은지
git diff --cached --stat # 수십 MB짜리 파일이 있으면 뭔가 잘못된 것
```

실수로 커밋했다면 `git rm --cached` 로 지우고, **이미 push 했다면
히스토리에 남으므로** `git filter-repo` 등으로 완전히 제거해야 합니다.

## 2. API 키 취급

### 넣어야 할 곳

| 환경 | 위치 | 코드 |
|---|---|---|
| Colab | 🔑 보안 비밀 → `AIHUB_API_KEY` → 노트북 액세스 ON | `userdata.get('AIHUB_API_KEY')` |
| Kaggle | Add-ons → Secrets → Attach | `UserSecretsClient().get_secret(...)` |
| 로컬 | `export AIHUB_API_KEY=...` | `os.environ[...]` |

이 프로젝트는 전부 `env.secret("AIHUB_API_KEY")` 하나로 통일했습니다.

### 넣으면 안 되는 곳

```python
APIKEY = "1234F316-E56E-..."     # ❌ 노트북에 그대로 남음
!aihubshell -aihubapikey 1234... # ❌ 셀 출력에 남음
```

노트북을 공유하거나 GitHub에 올리면 **그 순간 키가 공개**됩니다.
AI 어시스턴트(저 포함)에게 붙여넣는 것도 마찬가지입니다 — 대화 기록에 남습니다.

### 유출했다면

AI Hub 마이페이지에서 **키 재발급**하세요. 기존 키는 무효화됩니다.

## 3. 활용신청 절차

```
회원가입
   ↓
데이터셋 페이지 → [활용신청] 버튼
   ↓
활용 목적 작성 (연구/학습 목적이라고 쓰면 됩니다)
   ↓
승인 대기 ── 보통 1영업일 ──┐
                            ↓
                     마이페이지 → API Key 발급
                            ↓
                     이메일로 키 수신
```

**승인 전에는 `aihubshell` 이 동작하지 않습니다.**
목록 조회(`-mode l`)부터 실패하면 승인 여부를 먼저 확인하세요.

---

## 4. 만든 모델은 어떻게 되나

**모델 가중치도 조심해야 합니다.** 학습된 가중치는 원본 데이터를 그대로 담고 있진
않지만, AI Hub 약관상 산출물 활용 범위를 확인하는 게 안전합니다.

- 개인 학습·연구 목적 → 일반적으로 문제 없음
- **상용 서비스 배포** → 약관 확인 필수. 필요하면 AI Hub에 문의
- 논문·발표 → 출처 명시 (`AI Hub 반려동물 피부 질환 데이터, 한국지능정보사회진흥원`)

`.gitignore` 가 `*.pt` 도 막아두었습니다. 가중치가 필요하면 Drive나 별도 스토리지로.

---

## 5. 개인정보

이 데이터에 사람 얼굴은 없지만, 다음이 들어 있을 수 있습니다:

- 진료 기록 번호, 병원 식별자
- 보호자의 손 (사진에 나오는 경우)
- EXIF의 촬영 위치·시각·기기 정보

**매니페스트(`*.parquet`)에도 개체ID·차트번호가 들어갑니다.**
이것도 커밋 대상이 아닙니다 — `.gitignore` 에 포함되어 있습니다.

논문이나 발표에 이미지를 실을 때는 원본 그대로 쓰지 말고 크롭·마스킹하세요.
